# История изменений

Здесь перечислены заметные изменения ModbusReader. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

Начиная с 26.10.0, номера версий календарные — **ГГ.ММ.N**: 26.10.0 — первый
выпуск октября 2026 года, 26.10.1 — следующий выпуск того же месяца, 26.11.0 —
первый выпуск ноября. Предыдущие версии нумеровались 1.x и 2.0–2.2; новые
номера всегда больше старых, поэтому обновление сравнивает их корректно.

## [Не выпущено]

### Добавлено
- **Modbus TCP.** Программа подключается к приборам по сети: ПЛК, счётчикам,
  шлюзам — и к преобразователям RS-485 → Ethernet в режиме «RTU по TCP».
  Подключение настраивается в карточке, которая открывается щелчком по
  параметрам связи в шапке окна: там же «Проверить связь» — один запрос и
  понятная причина, если связи нет; для TCP проверка сама подбирает Unit ID и
  режим (Modbus TCP или RTU по TCP), если прибор отвечает иначе. Недавние
  подключения — там же, в один щелчок.
- Сканер ищет приборы Modbus TCP в локальной сети; двойной щелчок по
  найденному — подключиться.
- Эмулятор отвечает и по Modbus TCP (а также RTU по TCP) сразу нескольким
  мастерам. Мастер этой же программы может подключиться к своему эмулятору
  через 127.0.0.1 — проверка без оборудования.
- Консоль собирает кадры Modbus TCP с заголовком MBAP; журнал показывает
  кадры так, как они идут по сети.
- **Обновления — как в Telegram.** Новая версия скачивается и ставится в
  фоне, рядом с текущей, пока вы работаете; в боковой панели появляется
  «Обновить до …», и перезапуск занимает столько же, сколько обычный запуск.
  Не перезапустили — новая версия откроется при следующем запуске. Для
  установки «для всех пользователей» программа один раз спросит, потому что
  Windows попросит разрешение.
- Установщик в стиле программы: светлая или тёмная тема, как в Windows,
  логотип, одна своя страница вместо нескольких стандартных. По умолчанию
  предлагается установка «только для меня» — тогда обновления ставятся без
  единого вопроса Windows.

### Изменено
- Установщик и программа стали легче (36 МБ вместо 43): убраны программный
  OpenGL и PDF-модуль Qt, которыми программа не пользуется.
- Протокол Modbus (RTU и TCP) теперь реализован в самой программе; библиотека
  pymodbus больше не используется. Ошибки линии различаются точнее: ответ с
  неверной CRC, оборванный или искажённый кадр учитывается как ошибка CRC, а
  не как таймаут; эхо адаптера RS-485 и помехи перед ответом обрабатываются;
  ответ читается сразу, как только он полностью пришёл.

### Исправлено
- Демо-проект в английском интерфейсе показывал русские единицы, подписи
  режимов и заголовки виджетов. Теперь с английским интерфейсом открывается
  английский демо-проект.

## [26.10.2] — 2026-10-21

### Добавлено
- Сборки для **Linux** (`ModbusReader-x86_64.AppImage`) и **macOS** на Apple
  Silicon (`ModbusReader-macOS-arm64.zip`). Настройки на этих системах
  хранятся в папке пользователя; о новой версии программа сообщает и
  открывает страницу выпуска.

### Исправлено
- Статистика линии перестала бы считать ошибки CRC с новой версией
  библиотеки pymodbus (3.16): такие ошибки учитывались как таймауты.
- Адреса и значения на macOS и Linux выводились не моноширинным шрифтом.

### Изменено
- Версии библиотек закреплены; обновления проверяются тестами перед
  выпуском. Программа собрана с pymodbus 3.16, Qt 6.11.2 и PyInstaller 6.22.

## [26.10.1] — 2026-10-20

### Изменено
- Установщик спрашивает режим установки: для всех пользователей — в
  `C:\Program Files\ModbusReader` (с правами администратора, по умолчанию) или
  только для себя — без прав администратора. Обновление сохраняет выбранный
  режим; для установки на всех пользователей Windows попросит подтверждение, о
  чём заранее предупреждает окно обновления.
- Кнопка «Обзор…» в установщике открывает стандартный диалог выбора папки
  Windows: можно создать новую папку, работает контекстное меню. К выбранной
  папке автоматически добавляется `ModbusReader`.

## [26.10.0] — 2026-10-20

### Добавлено
- **Автообновление.** Программа проверяет наличие новой версии сразу после
  запуска и затем каждые шесть часов и предлагает установить её в одном окне:
  «Обновить», «Позже», «Пропустить эту версию»; если открыта подсказка
  первого запуска, предложение дожидается её закрытия. Загруженный файл сверяется с контрольной
  суммой SHA-256, которую GitHub публикует для каждого файла выпуска.
  Автоматическую проверку можно отключить в разделе «Настройки → Общие»;
  проверить вручную — «О программе → Проверить сейчас».
- **Установщик** `ModbusReader-Setup.exe`: установка для текущего
  пользователя без прав администратора, ярлыки в меню «Пуск» и на рабочем
  столе, открытие файлов `.mbproj` двойным щелчком, удаление через
  «Параметры → Приложения». Установленная программа хранит настройки в
  `%APPDATA%\ModbusReader`.
- **Демо-проект** «Демо-термоконтроллер»: карта регистров всех четырёх
  областей Modbus и пульт из 12 виджетов. Открывается автоматически при первом
  запуске и кнопкой «Демо-проект» на пустом экране карты; программа работает с
  его копией в папке «Документы\ModbusReader».
- **Открытый исходный код** под лицензией GNU GPL версии 3 или более поздней;
  лицензии сторонних компонентов перечислены в `THIRD_PARTY_LICENSES.md`.
  В разделе «О программе» — лицензия, ссылка на исходный код и ссылка для
  поддержки проекта.
- Журнал обмена: поиск, сохранение в текстовый файл, очистка.

### Изменено
- Номера версий стали календарными (см. выше).
- Новая заставка при запуске: в стиле оформления программы, со скруглёнными
  углами и тенью, показывает этап загрузки и ход запуска на языке
  интерфейса и плавно исчезает, когда окно готово.
- Окно «Наблюдение» переработано: собственная рамка, крупное значение,
  минимум, максимум и время последнего изменения, поле записи для регистров с
  доступом на запись, закрепление поверх других окон.
- Редактор карты: имя карты и счётчики регистров — в верхней строке,
  инструменты — под ними, команды «Сохранить», «Применить» и «Закрыть» — в
  нижней панели; предпросмотр JSON включается отдельной кнопкой; колонкам имён
  отводится свободная ширина.
- Настройки: увеличены интервалы между разделами, строки стали компактнее,
  подписи выровнены по заголовкам разделов.
- Пример макроса составлен для демо-проекта; к регистрам в макросах можно
  обращаться и по английским именам.
- Шрифт журнала обмена — основного размера интерфейса.
- Пустые экраны сканера, сниффера и дашборда не дублируют основную кнопку
  панели инструментов.
- Исходный код разложен по пакетам `app/`, `core/` и `gui/`.
- Документация: README с иллюстрациями, описание архитектуры, политика
  безопасности.

### Исправлено
- Главное окно могло открыться позади других программ и выглядеть
  свёрнутым: при запуске на мгновение появлялись и исчезали служебные окна,
  и Windows возвращала фокус предыдущей программе.
- Окно, закрытое на мониторе, который потом отключили, открывалось за
  пределами экрана; теперь оно возвращается на основной монитор.
- Редактор карты: после быстрого перетаскивания строк на таблице оставались
  изображения соседних строк.
- Клавиша Esc не закрывала редактор карты и настройки после переключения окон
  (Alt+Tab).
- Таблицы: чередующаяся заливка строк не захватывала колонку номеров, в
  заголовке отображались лишние разделители, между ячейками были видны швы.
- Подписи с внутренними отступами смещались вправо относительно полей под
  ними.
- Дашборд: при совпадении идентификаторов двух виджетов в файле один из них
  переставал получать значения и не сохранялся.
- Окно «Наблюдение»: у регистров только для чтения обрезалась строка
  сведений; единица масштабированного значения отображалась слитно с числом.
- Окно обновления: обрезалась последняя строка списка изменений.
- Подсказка в журнале эмулятора обрезалась.
- Сканер выводил единицу времени по-английски («ms»), колонка времени в
  предпросмотре логгера называлась «timestamp», таблица результатов макроса не
  занимала всю ширину.

## [2.2.0] — 2026-10-15

Новый интерфейс главного окна.

### Добавлено
- **Левая панель навигации** вместо вкладок вверху окна. Все экраны видны
  всегда и разделены на две группы: «Мониторинг» (карта регистров, дашборд) и
  «Инструменты» (консоль, сканер, сниффер, снимки, логгер, макросы, эмулятор).
  Настройки и справка — внизу панели. Панель сворачивается до значков; зелёная
  точка отмечает инструмент, работающий в фоне.
- **Шапка окна:** проект и текущий экран слева; параметры связи
  («COM3 · 115200 · 8N1 · ID 10», щелчок открывает настройки подключения) и
  кнопка «Подключить» справа. Состояние связи видно сразу.
- **Макросы** открываются как экран программы (Ctrl+M), а не отдельным окном;
  запущенный макрос продолжает работать при переходе на другие экраны.
- **Пустые экраны** поясняют своё назначение и предлагают первое действие.
- Кнопка «Изменить карту» на экране карты регистров.
- **Карточка графика:** крупное текущее значение с единицей и изменением за
  окно; минимум, максимум и среднее с единой точностью; шкала по фактическому
  диапазону окна; заливка под линией; состояния «Ожидание данных», «Нет данных»
  (при потере связи значение и линия тускнеют) и «Пауза»; кнопка «Развернуть».
- Сведения о версии в свойствах exe и заставка при запуске одиночного exe.

### Изменено
- Единое оформление кнопок: одна выделенная кнопка основного действия,
  остальные — второстепенные.
- Таблицы выровнены по левому краю; имя и значение — основным цветом, адрес и
  тип — приглушённым; длинное имя сокращается многоточием, не вытесняя
  значения за край таблицы.
- Колонка «Текущее значение» переименована в «Значение»; «Slave» в навигации —
  в «Эмулятор (Slave)».
- Форма настроек ограничена удобной шириной; редактор макросов использует
  моноширинный шрифт.
- Параметры связи перенесены из строки состояния в шапку.
- Ввод текста (запись значения, «Сохранить проект как», переименование
  дашборда) выполняется в диалогах в стиле программы вместо системного окна.
- Рамка фокуса нейтрального цвета; при открытии экрана курсор не переходит в
  первое поле автоматически.
- Журнал обмена, единицы измерения и подписи окон графиков выводятся на языке
  интерфейса.
- Заголовок окна содержит имя открытого документа.
- Раздел «О программе»: логотип, версия, актуальный перечень функций.
- Доработки оформления: значок режима дашборда «Работа / Редактирование»,
  переключатели и выбранный раздел настроек в цвете акцента, вкладки журнала
  с одной подчёркивающей линией, единый вид пустых состояний, иконки у всех
  кнопок снимков.

### Исправлено
- Команда «Копировать адрес» в меню таблицы копировала текст «Двоичное»
  вместо адреса (ошибка появилась в 2.1.0).
- При запуске заголовок окна на мгновение показывал устаревшее название.
- Пустой график показывал лишнюю подпись шкалы.
- В диалоге импорта обрезались списки назначения колонок.
- Пример макроса в английском интерфейсе был на русском.

## [2.1.0] — 2026-10-13

### Добавлено
- **Эмулятор прибора (Slave)** (Ctrl+9). Программа отвечает мастеру по
  открытой карте регистров: чтение FC 03/04, запись FC 06/16, исключения
  01/02/03; на чужой адрес и кадр с неверной контрольной суммой не отвечает.
  Значения задаются в таблице и кодируются теми же кодеками, что и при чтении;
  записи мастера отображаются сразу. Счётчики обращений к каждому регистру,
  журнал обмена, настраиваемая задержка ответа. Мастер и эмулятор не могут
  использовать один COM-порт.
- **Окно наблюдения** (F6): плавающее окно с выбранными регистрами, видимое
  на любом экране; может закрепляться поверх всех окон. Регистры добавляются
  из контекстного меню карты или виджета дашборда.
- **Статистика линии** в строке состояния: отправленные и полученные кадры,
  ошибки, среднее время ответа; подробно — таймауты, ошибки CRC, исключения
  Modbus, доля ответов, время ответа.
- **Типы данных:** UINT16, UINT32, INT64, DOUBLE, STRING, BCD16, BCD32,
  BITS16. 64-битные значения следуют настройкам порядка байт LONG/FLOAT и
  записываются без потери точности.
- **Области Modbus:** у регистра появилось необязательное поле «Область» —
  Holding (FC 03/06/16), Input (FC 04), Coil (FC 01/05), Discrete (FC 02).
  Адреса в таблице — «IR 0x0010», «CO 0x0010», «DI 0x0010». Эмулятор отвечает
  на FC 01/02/04/05/15, сниффер их разбирает, импорт понимает колонку
  «Область» и блоки 3xxxx/1xxxx, макросы — `reg("CO 5")`. Существующие карты и
  проекты не меняются.
- Иконка приложения.

### Изменено
- Импорт из Excel/CSV распознаёт «uint16», «word», «dword», «double», «bcd»,
  «string» как соответствующие типы (ранее беззнаковые значения читались как
  знаковые).
- Двоичное представление значений сгруппировано по 4 бита.
- Счётчик ошибок журнала перенесён на кнопку «Журнал».

## [2.0.0] — 2026-10-13

Первый финальный выпуск: полный аудит кода и интерфейса. Каждая найденная
ошибка воспроизведена, исправлена и закреплена тестом.

### Исправлено — критичные ошибки
- Чётность порта не применялась: любое подключение открывалось как 8N1, и
  приборы с 8E1 не отвечали.
- Не открывалось окно просмотра области памяти.
- Не открывалось контекстное меню таблицы, а с ним — добавление регистра на
  график.
- Редактор карты перенумеровывал все адреса подряд при любом изменении, что
  искажало карты с разрывами в адресах. Теперь смежные регистры сдвигаются
  вместе, регистр после разрыва сохраняет адрес, адрес можно задать вручную.
- Ctrl+S не работал в редакторе карты.

### Исправлено — данные и опрос
- Запись, поставленная в очередь до потери связи, отправлялась в прибор при
  следующем подключении; теперь она отменяется с сообщением.
- Макрос, ожидающий операцию при отключении, получает ошибку сразу.
- Неподтверждённая прибором запись из макроса вызывает исключение.
- Ошибка при открытии порта отображается в журнале и статусе.
- Быстрое «Отключить → Подключить» оставляло кнопку неработающей.
- Значения NaN и ±inf нарушали работу таблицы и графиков.
- Логгер и снимки получают числовые значения без единиц и форматирования.
- После потери связи логгер записывает пустые ячейки, а не последнее
  значение; повторный запуск не перезаписывает прежний файл без запроса.
- Логгер сразу видит загруженную карту.
- Регистры только для записи (W) записываются из таблицы.
- Значение, введённое без подключения, не терялось молча.
- Шестнадцатеричное представление 32-битных регистров содержит все 32 бита;
  для FLOAT — битовое представление IEEE 754.
- Для регистра с перечислением можно ввести подпись значения.

### Исправлено — проекты и файлы
- После перезапуска восстанавливается карта открытого проекта.
- «Новый проект» сбрасывает файл прежней карты; Slave ID обновляется при
  открытии проекта.
- Карта `.json`, выбранная в диалоге проекта, открывается как карта.
- «Редактировать карту» открывает текущую карту, а не пустой редактор.
- Файлы с версией 0 сообщают понятную ошибку.
- Импорт: адрес 40000 в режиме 4x соответствует 0; «write», «R/O», «W/O»
  распознаются верно; подписи вида «01 = …» не теряются.
- Ошибки экспорта и импорта дашборда отображаются.

### Изменено — интерфейс
- Панель редактора карты в две строки; подписи кнопок не обрезаются.
- Строка состояния: нейтральная точка в покое, счётчик учитывает только ошибки
  уровня ERR, формат линии отображается полностью (например, 8E1).
- Нижний журнал и экран «Консоль» показывают один общий журнал; история
  команд консоли общая.
- Точка состояния в таблице: зелёная — значение получено, кольцо — обмен
  регистра выводится в журнал.
- Страница «Горячие клавиши» формируется из реестра команд; «О программе» —
  дата выпуска и путь к файлу настроек.
- Начали действовать настройки «Автомасштаб оси Y», «Сглаживание линий»,
  видимость и высота журнала, ширина панели графиков.
- Полноэкранный график подписывает ось времени часами.
- Моноширинный шрифт значений следует размеру шрифта интерфейса.
- Кнопка «Добавить виджет» доступна в рабочем режиме дашборда.
- Единая терминология: «карта регистров» вместо «профиль».
- Сообщения ядра опроса и макросов переведены: в английском интерфейсе
  журнал больше не выводится на русском.
- Флажки отображают галочку; ошибки в строках состояния инструментов
  выделяются цветом.

### Исправлено — надёжность
- Непойманные ошибки записываются в `modbusreader_errors.log`; при сбое
  запуска показывается окно с причиной.
- Закрытие программы корректно останавливает выполняющийся макрос.
- Настройки по умолчанию не разделяют изменяемые списки с загруженными.
- Тесты изолированы от реального файла настроек.
