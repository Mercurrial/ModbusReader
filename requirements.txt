# ModbusReader — runtime dependencies, PINNED to the exact versions the
# releases are built and tested with.
#
# A new library version can change behaviour without failing anything
# (pymodbus 3.16 silenced the line statistics' CRC count), so updates are a
# decision, not an accident: Dependabot proposes them as a pull request every
# week, CI runs the tests on them, and only a merged bump reaches a build.
# tools/build_installer.py refuses to build in an environment that differs
# from these pins. What the code relies on inside the libraries is listed and
# tested in tests/test_library_contracts.py.
#
# Python 3.10+ (the code uses `X | None` unions); the releases use 3.12.
# Install:  python -m pip install -r requirements.txt
# For tests and builds: requirements-dev.txt
