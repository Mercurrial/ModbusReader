# Калькулятор CRC и разбор кадра

Пробелы, запятые и `0x` можно ставить как угодно; каждый байт — две цифры.
Всё считается в браузере, на сервер ничего не отправляется.

## Как считается CRC Modbus

CRC-16/MODBUS: полином `0xA001` (отражённый `0x8005`), начальное значение
`0xFFFF`, без финального XOR. Два байта CRC добавляются в конец кадра
**младшим байтом вперёд**: для `01 03 00 00 00 02` CRC равен `0x0BC4`, а в
кадре идут байты `C4 0B`.

```python
def crc16_modbus(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if crc & 1 else crc >> 1
    return crc

frame = bytes.fromhex("010300000002")
crc = crc16_modbus(frame)
packet = frame + bytes([crc & 0xFF, crc >> 8])   # 01 03 00 00 00 02 C4 0B
```

Прибор молча отбрасывает кадр с неверной CRC — поэтому ошибка в одном байте
выглядит как «прибор не отвечает». Структура кадра разобрана в разделе
[Что такое Modbus RTU](../modbus/index.md), коды функций и исключений — в
[Функции и ошибки](../modbus/functions.md).

## В программе

В ModbusReader CRC считать не нужно: [консоль](../guide/console.md)
добавляет её к любому кадру сама, журнал обмена расшифровывает каждый кадр, а
[сниффер](../guide/sniffer.md) помечает кадры с неверной CRC.
