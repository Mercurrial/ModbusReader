# Онлайн-инструменты

Три помощника для наладчика — работают прямо в браузере, ничего не
устанавливая и никуда не отправляя данные.

<div class="grid cards" markdown>

-   :material-shield-check:{ .lg .middle } [**Калькулятор CRC и разбор кадра**](crc.md)

    ---

    CRC16 Modbus для любого кадра, проверка готового пакета и расшифровка:
    адрес прибора, функция, регистры, исключение.

-   :material-swap-horizontal:{ .lg .middle } [**Конвертер FLOAT и INT32**](converter.md)

    ---

    Значение → регистры и регистры → значение во всех порядках байт: ABCD,
    CDAB, BADC, DCBA. FLOAT, DOUBLE, INT16…INT64.

-   :material-map-marker:{ .lg .middle } [**Адреса 40001 ↔ 0x0000**](address.md)

    ---

    Нотация Modicon, адрес протокола с нуля, номер с единицы, hex и dec,
    функции чтения и записи.

</div>

Всё это ModbusReader делает сам: считает CRC, раскладывает значения по
регистрам и показывает адреса в понятном виде. Инструменты пригодятся, когда
программы под рукой нет — или чтобы разобраться, почему другая программа
показывает странное значение.
