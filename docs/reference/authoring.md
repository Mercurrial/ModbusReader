# ModbusReader authoring contract

Generated by `tools/build_authoring.py`; edit the source contract, not this file.
Contract version: 1.

## Files and addressing

Create UTF-8 JSON with a current format/version envelope. This strict creation contract
does not replace the application's tolerant legacy loaders. Unknown fields are errors.
Addresses are zero-based integer offsets 0..65535; do not copy Modicon references such
as 40001 into addr. A multiword value occupies its type span, not just its starting address.
Register fields: addr, name, type, rw (required); length, area, name_en, unit, comment,
default, scale, offset, enum (optional). name_en aliases must not collide with other names.
Access codes: R/RO, W/WO, RW. Input/discrete tables cannot write; bit tables use BOOL x1.
Scale: displayed = decoded * scale + offset. Inverse: decoded = (displayed-offset)/scale.
enum is a JSON object mapping integer strings to labels, e.g. {"0":"Off","1":"On"}.
STRING length is in 16-bit words (two cp1251 bytes/word); cyclic reads are limited to 125 words.
A fixed-span type ignores length for its occupied span. Some registered types have no codec.

## Areas

| Area | Code | Macro prefix | Read FC | Write FC |
|---|---:|---|---:|---:|
| holding | 0 | (none) | 3 | 6 |
| input | 1 | IR | 4 | None |
| coil | 2 | CO | 1 | 5 |
| discrete | 3 | DI | 2 | None |

Numeric register key = (area code << 16) | addr. Dashboard reg_id is that key in hex:
input address 16 → 0x10010; coil address 5 → 0x20005. Macro string addresses use
IR 0x0010 / CO 0x0005 / DI 0x0005; names are case-insensitive and trimmed.

## Connection and byte orders

Projects contain connection, profile, dashboards and optional layout. Connection may be
empty (uses application settings); specify known device settings rather than guessing.
transport: serial / tcp / rtu_tcp / sim. TCP uses host and tcp_port; serial uses port,
baudrate, parity, stopbits. slave_id: 1..247 serial, 0..255 TCP transports.
timeout, poll_rate and interframe_delay are milliseconds. sim requires simulation=thermo.
Byte orders are shared by type families and live in project.connection:
order_short (AB/BA, default AB); order_long (ABCD/BADC/CDAB/DCBA, default ABCD);
order_float (same four orders, default BADC). Unsigned/BCD types follow the corresponding
integer family; INT64 follows order_long; DOUBLE follows order_float. They are not per-register settings.

## Dashboard

Each board has widgets and links. Each widget requires unique uid and kind; bound kinds
also require reg_id. x/y/w/h are logical pixels; defaults and minimum sizes are in the widget catalog.
Links use {"from":"source_uid","to":"target_uid"}, and require existing output/input ports.
Controls require writable numeric registers. Use --profile to verify standalone board bindings.
Kinds: value, led, bar, gauge, bits, chart, button, input, toggle, slider, select, timer, gate, label.
Fields and limits are in the JSON Schemas. Examples: gate uses cond/cmp; timer uses interval
(milliseconds, at least 50)/autostart; slider uses vmin/vmax/step/live; select uses
options: [[integer, label], ...]. Edit mode does not write. Validation does not simulate automation.

## Macro API

Python statements execute in a restricted namespace. Imports and dunder access are rejected.
No open/eval/exec/compile or exception-class builtins are supplied. AST checks are guardrails,
not a security sandbox. Validation never runs your script. Indirect/dynamic calls are not fully checked.
read/write/reg.value bypass engineering scale/offset. write returns the supplied value; it is
not a readback. Multiword writes are sequential, not atomic. Respect map access permissions.
reg returns a handle with read(), write(value), value (fresh I/O), addr (composite key), type and name.
Unknown numeric addresses require an explicit codec-backed dtype; device validity is still unverified.

### `reg(key, dtype=None) -> Register`

Register handle: .read(), .write(value), .value (a fresh read), .addr, .type, .name.

Объект регистра: .read(), .write(value), .value (новое чтение), .addr, .type, .name.

### `read(key, dtype=None) -> object`

Read a decoded value before scale/offset. Key: map name, address, or IR/CO/DI address string.

Прочитать декодированное значение без scale/offset. Ключ: имя, адрес или строка IR/CO/DI.

### `write(key, value, dtype=None) -> object`

Write a value before scale/offset; return the supplied value. Respect register access permissions.

Записать значение без scale/offset; вернуть переданное value. Учитывайте доступ регистра.

### `read_all() -> dict`

Read all codec-backed map entries, including STRING; return {name: value}.

Прочитать все типы с кодеками из карты, включая STRING; результат {имя: значение}.

### `wait(seconds) -> None`

Interruptible delay in seconds.

Прерываемая пауза в секундах.

### `sleep(seconds) -> None`

Alias of wait.

Псевдоним wait.

### `record(row=None, **kwargs) -> None`

Append a result row: a dict and/or named columns; keyword columns override dict keys.

Добавить строку результатов: словарь и/или именованные колонки; kwargs имеют приоритет.

### `log(*args) -> None`

Log arguments joined with spaces.

Сообщение в журнал; аргументы разделены пробелами.

### `print(*args) -> None`

Alias of log; sep/end/file are not supported.

Псевдоним log; sep/end/file не поддерживаются.

### `now() -> float`

Unix time in seconds, not a monotonic clock.

Unix-время в секундах, не монотонные часы.

### `timestamp() -> str`

Local time: YYYY-MM-DD HH:MM:SS.

Локальное время: YYYY-MM-DD HH:MM:SS.

Builtins: abs, min, max, round, sum, len, range, enumerate, zip, map, filter, sorted, reversed, int, float, str, bool, list, dict, tuple, set, frozenset, divmod, pow, bin, hex, oct, ord, chr, format, repr, any, all, isinstance.

## Validation boundaries

JSON Schema checks shape; CLI additionally checks spans, duplicate names/addresses, area/type
compatibility, bindings, ports and literal macro references/arity. Overlaps are warnings because
intentional aliases/service ranges exist. CLI does not prove runtime termination, timing, hardware
access rights, value ranges on the device or correctness of dynamically computed references.
Warnings do not make valid=false; use --warnings-as-errors for a nonzero exit on any diagnostic.
Diagnostics use JSON Pointer paths for files and 1-based line/column positions for Python.
