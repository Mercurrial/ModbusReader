# Исключение 03 — Illegal Data Value

**Исключение 03** (Illegal Data Value, «недопустимое значение данных»)
означает: прибор понял функцию и адрес, но **значение в запросе ему не
подходит**. По спецификации это прежде всего ошибка в **структуре**
запроса — неверное количество или длина; на практике многие приборы
отвечают 03 и на значение уставки вне допустимого диапазона.

```text
01 86 03 02 61
|  |  |
|  |  +-- исключение 03: Illegal Data Value
|  +----- 0x86 = ответ с ошибкой на функцию 06
+-------- прибор 1
```

## Причины { #causes }

### Количество вне пределов { #count }

| Функция | Допустимое количество |
|---|---|
| [01](../functions/01-read-coils.md), [02](../functions/02-read-discrete-inputs.md) — чтение битов | 1…2000 |
| [03](../functions/03-read-holding-registers.md), [04](../functions/04-read-input-registers.md) — чтение регистров | 1…125 |
| [15](../functions/15-write-multiple-coils.md) — запись битов | 1…1968 |
| [16](../functions/16-write-multiple-registers.md) — запись регистров | 1…123 |

Запрос на 0 регистров или на 126 — исключение 03. Многие приборы
ограничивают количество сильнее (16, 32, 64 регистра за раз) и отвечают 03
на всё, что больше.

### Число байт не сходится с количеством { #byte-count }

В функциях 15 и 16 есть поле «число байт данных», и оно обязано совпадать
с количеством: для 16 — ровно 2 × количество регистров, для 15 —
количество битов / 8 с округлением вверх. При ручной сборке кадра это
частая ошибка.

### Не FF 00 в функции 05 { #coil-value }

[Функция 05](../functions/05-write-single-coil.md) принимает только
`FF 00` (включить) и `00 00` (выключить). `00 01` — это исключение 03.

### Уставка вне диапазона { #range }

Прибор допускает температуру уставки 0…100 °C, а записано 150 — многие
приборы отвечают 03. Проверьте в документации **минимум, максимум и
масштаб**: если регистр хранит десятые доли, то 25,0 °C — это 250, а
запись 2500 — уже 250,0 °C, вне диапазона.

### Неверный тип или формат { #format }

- Отрицательное число в регистр без знака.
- FLOAT, записанный в неправильном порядке байт: прибор видит огромное или
  «нечисловое» значение и отказывает.
- Значение перечисления, которого нет в списке (режим 7 при допустимых
  0…3).

### Запись запрещена в текущем режиме { #mode }

Некоторые параметры можно менять только в определённом состоянии —
например, параметры двигателя у частотного преобразователя только на
остановленном приводе. Часть приборов отвечает при этом 03, часть — 04
или 01.

## Что делать { #fix }

1. Сверьте количество с пределами из таблицы выше и из документации
   прибора.
2. Прочитайте текущее значение регистра — оно подскажет масштаб и формат.
3. Запишите заведомо допустимое значение (например, текущее же) — если
   прошло, дело в диапазоне.
4. Для FLOAT проверьте порядок байт:
   [Типы данных и порядок байт](../data-types.md).

## В ModbusReader { #modbusreader }

Значение в колонке **«Новое значение»** вводится в инженерных единицах —
программа сама применяет масштаб и пишет сырое число, поэтому ошибка
«250 вместо 25,0» в ней не возникает, если масштаб в
[карте](../../guide/map-editor.md) задан верно. Если прибор ответил 03,
в журнале будет **«Запись не подтверждена»** с адресом регистра.
[Эмулятор](../../guide/slave.md) отвечает 03 на неверное количество или
длину — удобно проверить, как с этим справляется ваш мастер.
