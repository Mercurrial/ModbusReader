# Исключение 01 — Illegal Function

**Исключение 01** (Illegal Function, «недопустимая функция») означает:
прибор принял кадр, но **такой код функции он не поддерживает** — или не
может выполнить его сейчас, в текущем состоянии.

```text
01 83 01 80 F0
|  |  |
|  |  +-- исключение 01: Illegal Function
|  +----- 0x83 = ответ с ошибкой на функцию 03
+-------- прибор 1
```

## Частые причины { #causes }

### Чтение не той функцией { #read }

Прибор держит все данные в одной таблице и поддерживает только одну
функцию чтения:

- всё в **input-регистрах** → на [03](../functions/03-read-holding-registers.md)
  ответ 01, читать надо [04](../functions/04-read-input-registers.md);
- всё в **holding-регистрах** → на 04 ответ 01, читать надо 03;
- нет **coils** или **discrete inputs** → на 01 или 02 ответ 01.

**Проверить:** посмотрите в документации, какой функцией читается регистр
(«FC03», «FC04», адреса 3xxxx или 4xxxx), или просто попробуйте другую.

### Запись не той функцией { #write }

- Прибор принимает только [06](../functions/06-write-single-register.md),
  а запрос идёт функцией [16](../functions/16-write-multiple-registers.md) —
  частая история у простых датчиков и старых регуляторов.
- Прибор принимает только 16 (так бывает у контроллеров и приборов с
  32-битными уставками), а запрос идёт 06.
- Запись битов: только [05](../functions/05-write-single-coil.md) или
  только [15](../functions/15-write-multiple-coils.md).

### Функция есть, но не для этого регистра { #per-register }

Некоторые приборы отвечают 01, если функция в принципе поддерживается, но
не для запрошенной области — например, запись в регистр, который можно
только читать. Строго по спецификации это случай для исключения 02, но
производители трактуют по-разному.

### Неподходящий режим { #state }

Спецификация разрешает ответ 01 и тогда, когда функция поддерживается, но
прибор в состоянии, в котором её выполнить нельзя, — например, не
сконфигурирован или ждёт другой команды.

### Редкие и диагностические функции { #rare }

Функции 07, 08, 11, 17, 20–24, 43 поддерживает далеко не каждый прибор;
многие отвечают 01 на всё, кроме основных 01–06, 15 и 16.

## Что делать { #fix }

1. Найдите в документации прибора таблицу поддерживаемых функций — она
   обычно в начале раздела Modbus.
2. Если таблицы нет — попробуйте альтернативу: 03 ↔ 04, 06 ↔ 16,
   05 ↔ 15.
3. Если прибор за шлюзом — убедитесь, что 01 отвечает именно прибор, а не
   шлюз (у шлюза бывают свои ограничения на функции).

## В ModbusReader { #modbusreader }

Функция чтения в ModbusReader определяется **областью** строки карты: 4x
Holding — 03, 3x Input — 04, 0x Coil — 01, 1x Discrete — 02. Если прибор
отвечает исключением 01, поменяйте область строки в
[редакторе карты](../../guide/map-editor.md). Запись идёт функциями 05 и
06; если прибор принимает только 16 или 15 — отправьте кадр из
[консоли](../../guide/console.md). [Эмулятор](../../guide/slave.md) сам
отвечает исключением 01 на всё, кроме 01–06, 15 и 16.
