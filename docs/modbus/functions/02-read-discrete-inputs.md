# Функция 02 — Read Discrete Inputs

**Функция 02** (0x02, Read Discrete Inputs) читает состояние одного или
нескольких **дискретных входов** — битов таблицы 1x, доступных только для
чтения. Это то, что прибор «видит» снаружи: концевик, датчик двери, сухой
контакт, сигнал аварии. Записать дискретный вход нельзя — его состояние
задаёт внешний мир.

| Свойство | Значение |
|---|---|
| Код | 2 (0x02) |
| Таблица | Discrete inputs (1x) |
| Действие | Чтение |
| За один запрос | 1…2000 битов |
| Широковещательно (адрес 0) | Нет |

## Запрос { #request }

Формат тот же, что у [функции 01](01-read-coils.md):

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 1…247 |
| Код функции | 1 | `02` |
| Адрес первого входа | 2 | 0x0000…0xFFFF |
| Количество входов | 2 | 1…2000 |
| CRC16 | 2 | младший байт первым |

Прочитать у прибора 1 двадцать два входа начиная с адреса 196 (0x00C4; в
нотации Modicon — 10197):

```text
01 02 00 C4 00 16 B8 39
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- количество: 22
|  |    +-------------- адрес первого входа: 196
|  +------------------- функция 02
+---------------------- адрес прибора: 1
```

## Ответ { #response }

```text
01 02 03 AC DB 35 22 88
|  |  |  +--+--+  +-+-+
|  |  |     |       +-- CRC16
|  |  |     +---------- биты входов 196...217
|  |  +---------------- 3 байта (22 бита -> 3 байта)
|  +------------------- функция 02
+---------------------- адрес прибора: 1
```

Биты упакованы так же, как в [функции 01](01-read-coils.md#bit-packing):
первый вход — младший бит первого байта. Байт `0xAC` = `1010 1100` даёт
входы 196…203 справа налево: 0, 0, 1, 1, 0, 1, 0, 1. Последний байт `0x35`
= `0011 0101` несёт шесть оставшихся входов (212…217): 1, 0, 1, 0, 1, 1;
два старших бита — дополнение нулями.

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 82 01 81 60` | 01 | У прибора нет дискретных входов |
| `01 82 02 C1 61` | 02 | Нет входа с таким адресом или блок выходит за край |
| — | 03 | Количество 0 или больше 2000 |
| — | 04 | Прибор не смог прочитать входы |

## Coils или discrete inputs? { #coils-or-inputs }

| | Coils (функция 01) | Discrete inputs (функция 02) |
|---|---|---|
| Что это | Выходы, команды, флаги | Входы, состояния снаружи |
| Запись | Да (05, 15) | Нет |
| Нотация Modicon | 0xxxx | 1xxxx |

Как и с регистрами, производители следуют этому по-разному: у одних
приборов входы — только discrete inputs, у других те же биты доступны и
через coils, у третьих — битами holding-регистра. Смотрите документацию:
**1xxxx**, **FC02**, **Discrete Input** — значит функция 02.

## В ModbusReader { #modbusreader }

Строки карты с областью **1x Discrete** программа читает функцией 02;
тип — `BOOL`, доступ — только чтение. Кадры 02 видно в журнале обмена и в
[сниффере](../../guide/sniffer.md); [эмулятор](../../guide/slave.md) отвечает
на 02 своими входами.
