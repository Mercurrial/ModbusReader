# Функция 05 — Write Single Coil

**Функция 05** (0x05, Write Single Coil) включает или выключает один
**coil** — бит таблицы 0x. Так подают команды: включить реле, запустить
насос, сбросить аварию, перевести прибор в ручной режим.

| Свойство | Значение |
|---|---|
| Код | 5 (0x05) |
| Таблица | Coils (0x) |
| Действие | Запись одного бита |
| Значения | `FF 00` — включить, `00 00` — выключить |
| Широковещательно (адрес 0) | Да, без ответа |

## Запрос { #request }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 0…247 |
| Код функции | 1 | `05` |
| Адрес бита | 2 | 0x0000…0xFFFF |
| Значение | 2 | `FF 00` или `00 00` |
| CRC16 | 2 | младший байт первым |

Включить у прибора 1 coil с адресом 172 (0x00AC):

```text
01 05 00 AC FF 00 4C 1B
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- FF 00 = включить
|  |    +-------------- адрес бита: 172
|  +------------------- функция 05
+---------------------- адрес прибора: 1
```

Выключить тот же бит:

```text
01 05 00 AC 00 00 0D EB
```

!!! warning "Только FF 00 и 00 00"
    Значение — не «1» и не «0», а ровно `FF 00` или `00 00`. Любое другое
    (`00 01`, `01 00`) прибор обязан отвергнуть
    [исключением 03](index.md#exceptions). Это частая ошибка при ручной
    сборке кадра.

## Ответ { #response }

Прибор отвечает **копией запроса** — байт в байт:

```text
01 05 00 AC FF 00 4C 1B
```

Эхо означает, что команда принята. Ответ отправляется после того, как
бит изменён; но если бит управляет чем-то физическим (реле, пускатель),
эхо не гарантирует, что механизм уже сработал, — проверяйте по состоянию,
если это важно.

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 85 01 83 50` | 01 | Прибор не поддерживает запись coils |
| `01 85 02 C3 51` | 02 | Нет бита с таким адресом |
| `01 85 03 02 91` | 03 | Значение не `FF 00` и не `00 00` |
| — | 04 | Прибор не смог выполнить команду |

## На практике { #notes }

- **Команды-импульсы.** Многие приборы сами сбрасывают «командные» coils
  после выполнения: записали 1 — прибор выполнил сброс аварии и вернул 0.
  Прочитав бит сразу после записи, вы можете увидеть уже 0 — это нормально.
- **Широковещательно.** Запрос с адресом 0 выполнят все приборы на линии,
  но не ответит ни один — проверить результат можно только чтением.
- **Несколько битов** за один запрос пишет
  [функция 15](15-write-multiple-coils.md).
- **Бит в регистре.** Если флаг лежит битом внутри holding-регистра, а не в
  coils, функция 05 к нему не подходит — нужна запись регистра
  ([06](06-write-single-register.md)) или запись по маске (функция 22).

## В ModbusReader { #modbusreader }

Бит из строки карты с областью **0x Coil** программа пишет функцией 05:
введите `1`/`0`, `on`/`off` или `вкл`/`выкл` в колонке **«Новое значение»**.
Если прибор ответил исключением или не ответил, в журнале будет
**«Запись не подтверждена»** — причины разобраны в
[Решении проблем](../../troubleshooting.md). Кадр 05 с любым адресом можно отправить и из
[консоли](../../guide/console.md), а [эмулятор](../../guide/slave.md)
принимает 05 и меняет свой бит.
