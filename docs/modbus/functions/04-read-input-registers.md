# Функция 04 — Read Input Registers

**Функция 04** (0x04, Read Input Registers) читает подряд один или
несколько **input-регистров** — 16-битных слов таблицы 3x. Это регистры
только для чтения: в них приборы обычно кладут то, что измеряют, —
температуру, ток, напряжение, расход. Записать в input-регистр нельзя ни
одной функцией.

| Свойство | Значение |
|---|---|
| Код | 4 (0x04) |
| Таблица | Input registers (3x) |
| Действие | Чтение |
| За один запрос | 1…125 регистров |
| Широковещательно (адрес 0) | Нет |

## Запрос { #request }

Формат тот же, что у [функции 03](03-read-holding-registers.md), — меняется
только код функции:

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 1…247 |
| Код функции | 1 | `04` |
| Начальный адрес | 2 | 0x0000…0xFFFF |
| Количество регистров | 2 | 1…125 |
| CRC16 | 2 | младший байт первым |

Прочитать у прибора 1 один input-регистр по адресу 8 (в нотации
Modicon — 30009):

```text
01 04 00 08 00 01 B0 08
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- количество: 1
|  |    +-------------- начальный адрес: 0x0008
|  +------------------- функция 04
+---------------------- адрес прибора: 1
```

## Ответ { #response }

```text
01 04 02 00 0A 39 37
|  |  |  +-+-+ +-+-+
|  |  |    |     +-- CRC16
|  |  |    +-------- регистр 0x0008 = 0x000A = 10
|  |  +------------- 2 байта данных
|  +---------------- функция 04
+------------------- адрес прибора: 1
```

Число байт данных — удвоенное количество регистров, каждый регистр —
старший байт первым. Как превратить слова в FLOAT или 32-битное целое —
[Типы данных и порядок байт](../data-types.md).

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 84 01 82 C0` | 01 | Прибор не поддерживает функцию 04 — все его данные в holding-регистрах |
| `01 84 02 C2 C1` | 02 | Нет input-регистра с таким адресом или блок выходит за край |
| — | 03 | Количество 0 или больше 125 |
| — | 04 | Прибор не смог получить значение (например, неисправен датчик) |

## 03 или 04? { #03-or-04 }

Протокол разделяет «что прибор измеряет» (input, только чтение) и «что
можно настроить» (holding, чтение и запись). Производители следуют этому
по-разному:

- **Строго:** измерения — в input (функция 04), уставки — в holding (03).
  Так делают многие счётчики электроэнергии и модули ввода.
- **Всё в holding:** и измерения, и настройки читаются функцией 03, а 04
  прибор не поддерживает (исключение 01).
- **Одно и то же в обеих таблицах:** некоторые приборы отдают одинаковые
  данные и на 03, и на 04.

Подсказка — в документации: адрес вида **3xxxx** или пометка
**FC04 / Input Register** означает функцию 04; **4xxxx**, **FC03**,
**Holding** — функцию 03. Если документации нет — попробуйте обе: прибор
ответит данными на одну и исключением на другую.

## В ModbusReader { #modbusreader }

Регистры с областью **3x Input** в [карте регистров](../../guide/map-editor.md)
программа читает функцией 04; записывать их она не даёт — доступ у них всегда
«R». При импорте карты из Excel или CSV адреса вида 3xxxx сами попадают в
эту область. Кадры 04 видно в журнале обмена, в [сниффере](../../guide/sniffer.md)
и можно отправить из [консоли](../../guide/console.md);
[эмулятор](../../guide/slave.md) отвечает на 04 своими input-регистрами.
