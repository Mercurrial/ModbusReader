# Функция 01 — Read Coils

**Функция 01** (0x01, Read Coils) читает состояние одного или нескольких
**coils** — битов таблицы 0x, которые можно и читать, и записывать. Название
осталось от релейных схем («катушка» реле); сегодня это любые
включаемые и выключаемые признаки: реле и дискретные выходы, команды «пуск»
и «стоп», флаги режимов.

| Свойство | Значение |
|---|---|
| Код | 1 (0x01) |
| Таблица | Coils (0x) |
| Действие | Чтение |
| За один запрос | 1…2000 битов |
| Широковещательно (адрес 0) | Нет |

## Запрос { #request }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 1…247 |
| Код функции | 1 | `01` |
| Адрес первого бита | 2 | 0x0000…0xFFFF |
| Количество битов | 2 | 1…2000 (0x0001…0x07D0) |
| CRC16 | 2 | младший байт первым |

Прочитать у прибора 1 девятнадцать coils начиная с адреса 19 (0x0013):

```text
01 01 00 13 00 13 8C 02
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- количество: 19
|  |    +-------------- адрес первого бита: 19
|  +------------------- функция 01
+---------------------- адрес прибора: 1
```

## Ответ { #response }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | |
| Код функции | 1 | `01` |
| Число байт данных | 1 | количество битов / 8, с округлением вверх |
| Биты | N | по 8 битов в байте |
| CRC16 | 2 | |

```text
01 01 03 CD 6B 05 42 82
|  |  |  +--+--+  +-+-+
|  |  |     |       +-- CRC16
|  |  |     +---------- 3 байта битов
|  |  +---------------- число байт: 3 (19 битов -> 3 байта)
|  +------------------- функция 01
+---------------------- адрес прибора: 1
```

### Как упакованы биты { #bit-packing }

Первый запрошенный бит — **младший** бит первого байта данных, дальше по
порядку. В байте читайте справа налево:

```text
байт 0xCD = 1 1 0 0 1 1 0 1
            | | | | | | | +-- адрес 19 = 1
            | | | | | | +---- адрес 20 = 0
            | | | | | +------ адрес 21 = 1
            | | | | +-------- адрес 22 = 1
            | | | +---------- адрес 23 = 0
            | | +------------ адрес 24 = 0
            | +-------------- адрес 25 = 1
            +---------------- адрес 26 = 1
```

Второй байт `0x6B` — адреса 27…34, третий `0x05` (`0000 0101`) — адреса
35…37: 1, 0, 1. Лишние старшие биты последнего байта прибор заполняет
нулями.

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 81 01 81 90` | 01 | У прибора нет coils или он не поддерживает функцию 01 |
| `01 81 02 C1 91` | 02 | Нет бита с таким адресом или блок выходит за край |
| — | 03 | Количество 0 или больше 2000 |
| — | 04 | Прибор не смог прочитать состояние |

## На практике { #notes }

- **Coils и биты регистров — разные вещи.** Многие приборы хранят признаки
  не в coils, а битами внутри holding-регистра («слово состояния»). Такие
  биты читают функцией [03](03-read-holding-registers.md) и выделяют маской.
- **Адреса 00001.** В нотации Modicon coils пишут как 00001…09999 (или
  000001…); в кадр идёт адрес с нуля: 00001 → 0.
- **Блоками экономнее.** Один запрос на 100 битов занимает на линии почти
  столько же, сколько запрос на один, — если биты идут подряд, читайте их
  вместе.

## В ModbusReader { #modbusreader }

Строки карты с областью **0x Coil** программа читает функцией 01; тип у
таких строк всегда `BOOL`. Записать бит можно в колонке **«Новое значение»**
([как](../../guide/register-map.md)) — `1`/`0`, `on`/`off`, `вкл`/`выкл`;
запись уходит [функцией 05](05-write-single-coil.md).
Кадры 01 видно в журнале обмена и в [сниффере](../../guide/sniffer.md);
[эмулятор](../../guide/slave.md) отвечает на 01 своими coils.
