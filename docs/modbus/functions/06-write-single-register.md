# Функция 06 — Write Single Register

**Функция 06** (0x06, Write Single Register) записывает одно 16-битное
значение в один **holding-регистр** (таблица 4x). Так меняют уставки,
настройки, режимы работы — всё, что прибор хранит в одном слове.

| Свойство | Значение |
|---|---|
| Код | 6 (0x06) |
| Таблица | Holding registers (4x) |
| Действие | Запись одного регистра |
| Значение | 0x0000…0xFFFF |
| Широковещательно (адрес 0) | Да, без ответа |

## Запрос { #request }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 0…247 |
| Код функции | 1 | `06` |
| Адрес регистра | 2 | 0x0000…0xFFFF |
| Значение | 2 | старший байт первым |
| CRC16 | 2 | младший байт первым |

Записать в регистр 1 прибора 1 значение 3:

```text
01 06 00 01 00 03 98 0B
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- значение: 3
|  |    +-------------- адрес регистра: 1
|  +------------------- функция 06
+---------------------- адрес прибора: 1
```

## Ответ { #response }

Прибор отвечает **копией запроса** — это подтверждение записи:

```text
01 06 00 01 00 03 98 0B
```

Если ответ отличается от запроса или не пришёл вовсе, считать запись
выполненной нельзя: прочитайте регистр ещё раз
[функцией 03](03-read-holding-registers.md).

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 86 01 83 A0` | 01 | Прибор не поддерживает функцию 06 (бывает: только [16](16-write-multiple-registers.md)) |
| `01 86 02 C3 A1` | 02 | Нет регистра с таким адресом или он только для чтения |
| `01 86 03 02 61` | 03 | Значение вне допустимого диапазона уставки |
| — | 04 | Прибор не смог сохранить значение |

## Какое число записывать { #value }

Значение — 16 бит, а что они значат, решает прибор:

- **Отрицательные числа** (тип INT16) записываются в дополнительном коде:
  −1 → `FF FF`, −10 → `FF F6`.
- **Масштаб.** Если в документации «уставка, ×0,1 °C», то 25,0 °C — это
  250 (`00 FA`), а не 25.
- **32-битные значения** (FLOAT, INT32) занимают два регистра. Функцией 06
  их пишут двумя запросами — сначала одно слово, потом другое. Между
  запросами прибор хранит «половину» нового числа и «половину» старого; если
  он сразу применяет значение, это может на мгновение дать мусор. Надёжнее
  записать оба регистра одним запросом
  [функции 16](16-write-multiple-registers.md).

## На практике { #notes }

- **EEPROM не вечна.** Многие приборы сохраняют уставки в энергонезависимой
  памяти с ресурсом 100 000 — 1 000 000 записей. Запись каждую секунду
  в цикле «съест» её за дни или месяцы. Пишите только когда значение
  меняется; для частых изменений у некоторых приборов есть отдельные
  регистры «без сохранения».
- **Пароль и разрешение записи.** Часть приборов принимает запись настроек
  только после записи пароля или кода разблокировки в служебный регистр —
  без этого ответ будет исключением 02 или 03.
- **Широковещательно** удобно задать одну уставку всем приборам сразу, но
  подтверждения не будет ни от одного.

## В ModbusReader { #modbusreader }

Значение регистра с доступом `RW` или `W` вводится в колонке **«Новое
значение»** в инженерных единицах: программа сама применяет масштаб и
отправляет кадр 06. Многорегистровые значения (FLOAT, LONG) она пишет по
одному слову функцией 06; если прибор требует функцию 16, отправьте кадр из
[консоли](../../guide/console.md). [Эмулятор](../../guide/slave.md) принимает
06 и меняет свой регистр, а [сниффер](../../guide/sniffer.md) показывает
чужие записи.
