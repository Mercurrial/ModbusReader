# Функция 16 — Write Multiple Registers

**Функция 16** (0x10, Write Multiple Registers) записывает подряд несколько
**holding-регистров** одним запросом. Это основной способ записать
значение, занимающее больше одного регистра, — FLOAT, 32- и 64-битное целое,
строку, — а также сразу группу уставок.

| Свойство | Значение |
|---|---|
| Код | 16 (0x10) |
| Таблица | Holding registers (4x) |
| Действие | Запись нескольких регистров |
| За один запрос | 1…123 регистра |
| Широковещательно (адрес 0) | Да, без ответа |

## Запрос { #request }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 0…247 |
| Код функции | 1 | `10` |
| Начальный адрес | 2 | 0x0000…0xFFFF |
| Количество регистров | 2 | 1…123 (0x0001…0x007B) |
| Число байт данных | 1 | 2 × количество |
| Значения | 2 × N | каждый регистр — старший байт первым |
| CRC16 | 2 | младший байт первым |

Записать в регистры 1 и 2 прибора 1 значения 10 и 258:

```text
01 10 00 01 00 02 04 00 0A 01 02 92 30
|  |  +-+-+ +-+-+ |  +-+-+ +-+-+ +-+-+
|  |    |     |   |    |     |     +-- CRC16
|  |    |     |   |    |     +-------- регистр 2 = 0x0102 = 258
|  |    |     |   |    +-------------- регистр 1 = 0x000A = 10
|  |    |     |   +------------------- 4 байта данных
|  |    |     +----------------------- количество: 2
|  |    +----------------------------- начальный адрес: 1
|  +---------------------------------- функция 16 (0x10)
+------------------------------------- адрес прибора: 1
```

## Ответ { #response }

Прибор возвращает начальный адрес и количество записанных регистров:

```text
01 10 00 01 00 02 10 08
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- записано регистров: 2
|  |    +-------------- с адреса: 1
|  +------------------- функция 16
+---------------------- адрес прибора: 1
```

## Запись FLOAT { #float }

Число 25.0 в формате IEEE 754 — `41 C8 00 00`. Записать его в регистры 2–3
прибора 1 в порядке ABCD:

```text
01 10 00 02 00 02 04 41 C8 00 00 E7 B4
```

Если прибор хранит FLOAT в другом порядке слов или байт, данные в кадре
переставляются: для CDAB — `00 00 41 C8`, для BADC — `C8 41 00 00`, для
DCBA — `00 00 C8 41`. Какой порядок у вашего прибора и как его подобрать —
[Типы данных и порядок байт](../data-types.md); разложить любое число по
регистрам — [конвертер FLOAT](../../tools/converter.md).

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 90 01 8D C0` | 01 | Прибор не поддерживает функцию 16 — пишите по одному регистру [функцией 06](06-write-single-register.md) |
| `01 90 02 CD C1` | 02 | Блок выходит за пределы регистров или задевает регистр только для чтения |
| `01 90 03 0C 01` | 03 | Количество 0 или больше 123, число байт не равно 2 × количество, или значение вне диапазона |
| — | 04 | Прибор не смог сохранить значения |

## 16 или 06? { #16-or-06 }

| | Функция 06 | Функция 16 |
|---|---|---|
| Регистров за запрос | 1 | 1…123 |
| Ответ | копия запроса | адрес и количество |
| 32-битное значение | двумя запросами, между ними — «половина» числа | одним запросом |
| Поддержка | почти везде | почти везде, но не всегда |

Есть приборы, которые принимают только одну из двух: старые и простые —
только 06, некоторые контроллеры и приборы с 32-битными уставками — только
16 (на 06 они отвечают исключением 01 или 02). Если запись одной функцией
не проходит — попробуйте другую. Функцию 16 можно использовать и для
одного регистра: количество 1, число байт 2.

## В ModbusReader { #modbusreader }

При опросе программа пишет функцией 06 — многорегистровые значения по
одному слову. Если прибор требует функцию 16, соберите кадр в
[консоли](../../guide/console.md), например запись FLOAT выше, — CRC
консоль добавит сама. [Эмулятор](../../guide/slave.md) принимает функцию 16,
а [сниффер](../../guide/sniffer.md) расшифровывает её: видно, какие значения
записал другой мастер.
