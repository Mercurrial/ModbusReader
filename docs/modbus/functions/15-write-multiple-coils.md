# Функция 15 — Write Multiple Coils

**Функция 15** (0x0F, Write Multiple Coils) записывает подряд несколько
**coils** — битов таблицы 0x — одним запросом. Удобно, когда нужно
переключить сразу группу выходов: все реле модуля, набор флагов режима.

| Свойство | Значение |
|---|---|
| Код | 15 (0x0F) |
| Таблица | Coils (0x) |
| Действие | Запись нескольких битов |
| За один запрос | 1…1968 битов |
| Широковещательно (адрес 0) | Да, без ответа |

## Запрос { #request }

| Поле | Байт | Значение |
|---|:---:|---|
| Адрес прибора | 1 | 0…247 |
| Код функции | 1 | `0F` |
| Адрес первого бита | 2 | 0x0000…0xFFFF |
| Количество битов | 2 | 1…1968 (0x0001…0x07B0) |
| Число байт данных | 1 | количество / 8, с округлением вверх |
| Биты | N | по 8 в байте, первый бит — младший |
| CRC16 | 2 | младший байт первым |

Записать у прибора 1 десять coils начиная с адреса 19:

```text
01 0F 00 13 00 0A 02 CD 01 72 CB
|  |  +-+-+ +-+-+ |  +-+-+ +-+-+
|  |    |     |   |    |     +-- CRC16
|  |    |     |   |    +-------- биты: CD 01
|  |    |     |   +------------- 2 байта данных
|  |    |     +----------------- количество: 10
|  |    +----------------------- адрес первого бита: 19
|  +---------------------------- функция 15 (0x0F)
+------------------------------- адрес прибора: 1
```

Биты упакованы как в [функции 01](01-read-coils.md#bit-packing):
`0xCD` = `1100 1101` задаёт адреса 19…26 справа налево — 1, 0, 1, 1, 0, 0,
1, 1; `0x01` = `0000 0001` задаёт адреса 27 и 28 — 1 и 0, а старшие шесть
битов не используются и должны быть нулями.

## Ответ { #response }

Прибор возвращает адрес и количество — без самих битов:

```text
01 0F 00 13 00 0A 24 09
|  |  +-+-+ +-+-+ +-+-+
|  |    |     |     +-- CRC16
|  |    |     +-------- записано битов: 10
|  |    +-------------- с адреса: 19
|  +------------------- функция 15
+---------------------- адрес прибора: 1
```

## Ошибки { #exceptions }

| Ответ | Исключение | Когда |
|---|:---:|---|
| `01 8F 01 85 F0` | 01 | Прибор не поддерживает функцию 15 — пишите по одному биту [функцией 05](05-write-single-coil.md) |
| `01 8F 02 C5 F1` | 02 | Блок выходит за пределы существующих coils |
| `01 8F 03 04 31` | 03 | Количество 0 или больше 1968, или число байт не сходится с количеством |
| — | 04 | Прибор не смог записать биты |

## На практике { #notes }

- **Пишутся все биты блока.** Нельзя «пропустить» бит в середине — его
  значение из кадра тоже запишется. Чтобы поменять один бит, не трогая
  соседей, используйте [функцию 05](05-write-single-coil.md) или сначала
  прочитайте блок функцией 01.
- **Число байт** обязано совпадать с количеством: 10 битов — 2 байта,
  16 битов — 2 байта, 17 битов — 3 байта. Ошибка здесь — частая причина
  исключения 03 при ручной сборке кадра.
- **Одновременность.** Обычно прибор применяет все биты одного запроса
  вместе — это важно для групп выходов, которые должны переключаться одновременно.

## В ModbusReader { #modbusreader }

При опросе программа пишет coils по одному функцией 05. Кадр 15 для записи
группы битов можно отправить из [консоли](../../guide/console.md) — CRC она
добавит сама. [Эмулятор](../../guide/slave.md) принимает функцию 15, а
[сниффер](../../guide/sniffer.md) расшифровывает её в чужом обмене.
