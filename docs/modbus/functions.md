# Функции и коды ошибок

## Коды функций

Код функции во втором байте кадра говорит прибору, что сделать.

| Код | Hex | Функция | Таблица |
|:---:|:---:|---|---|
| 1 | `01` | Read Coils — чтение битов | Coils |
| 2 | `02` | Read Discrete Inputs — чтение входов | Discrete inputs |
| 3 | `03` | Read Holding Registers — чтение регистров | Holding |
| 4 | `04` | Read Input Registers — чтение входных регистров | Input |
| 5 | `05` | Write Single Coil — запись одного бита | Coils |
| 6 | `06` | Write Single Register — запись одного регистра | Holding |
| 15 | `0F` | Write Multiple Coils — запись нескольких битов | Coils |
| 16 | `10` | Write Multiple Registers — запись нескольких регистров | Holding |
| 8 | `08` | Diagnostics — диагностика линии | — |
| 22 | `16` | Mask Write Register — запись по маске | Holding |
| 23 | `17` | Read/Write Multiple Registers | Holding |

Функция 05 пишет `FF 00`, чтобы включить бит, и `00 00`, чтобы выключить.

### Какие функции использует ModbusReader

| Режим | Функции |
|---|---|
| Опрос (мастер) | чтение — 01, 02, 03, 04; запись — 05 (биты) и 06 (регистры) |
| [Эмулятор](../guide/slave.md) | отвечает на 01, 02, 03, 04, 05, 06, 15, 16; на остальные — исключением 01 |
| [Сниффер](../guide/sniffer.md) | расшифровывает 01–06, 08, 15, 16, 22, 23; остальное показывает байтами |
| [Консоль](../guide/console.md) | любой кадр, который вы наберёте |

!!! note "Запись 32-битных значений"
    FLOAT, LONG и другие многорегистровые значения мастер записывает
    **по одному слову функцией 06** — по очереди, с паузой между
    запросами. Большинство приборов это принимает. Если ваш прибор требует
    записывать такие значения только целиком функцией 16, отправьте кадр из
    [консоли](../guide/console.md), например:
    `01 10 00 02 00 02 04 41 C8 00 00` — записать FLOAT 25.0 в регистры
    0x0002–0x0003 прибора 1 (CRC консоль добавит сама).

## Исключения { #exceptions }

Если прибор получил кадр с верной CRC, но не может выполнить запрос, он
отвечает **исключением**: код функции с установленным старшим битом
(`03` → `83`, `06` → `86`) и один байт кода ошибки.

```text
01 83 02 C0 F1    прибор 1, функция 03, исключение 02 — недопустимый адрес данных
```

| Код | Название | Что значит | Что проверить |
|:---:|---|---|---|
| `01` | Illegal Function | Прибор не поддерживает эту функцию | Таблицу регистра: может, нужен FC 04 вместо FC 03 |
| `02` | Illegal Data Address | Такого адреса нет (или диапазон выходит за край) | Смещение на единицу, hex/dec, таблицу, длину FLOAT/строки |
| `03` | Illegal Data Value | Недопустимое значение или количество | Диапазон уставки, тип данных, запись в регистр только для чтения |
| `04` | Slave Device Failure | Внутренняя ошибка прибора | Состояние прибора, документацию |
| `05` | Acknowledge | Запрос принят, выполнение долгое | Повторите запрос позже |
| `06` | Slave Device Busy | Прибор занят | Увеличьте паузу между запросами |
| `08` | Memory Parity Error | Ошибка памяти прибора | Документацию прибора |
| `0A` | Gateway Path Unavailable | Шлюз не нашёл путь | Настройки шлюза |
| `0B` | Gateway Target Failed to Respond | Прибор за шлюзом молчит | Адрес и связь за шлюзом |

Исключение — хорошая новость: **связь есть**, прибор вас слышит и отвечает.
Проблема в запросе, а не в проводах. Нет ответа вовсе — это уже
[таймаут](../troubleshooting.md#timeout).

### Где видно исключения в ModbusReader

- В журнале обмена — строка ошибки с разбором кадра.
- В статистике линии (правый нижний угол) — счётчик **«Исключения Modbus»**.
- В [сканере](../guide/scanner.md) прибор, ответивший исключением, помечен
  **«Жив (исключение)»**: он есть на линии, просто не отдал регистр 0.
- В [сниффере](../guide/sniffer.md) кадры-исключения подсвечены.

## Без ответа и ошибки CRC

Не каждая проблема — исключение:

| Что видно | Причина |
|---|---|
| **Таймаут** — ответа нет | Неверные порт, скорость, чётность, адрес прибора; перепутаны A/B; прибор выключен |
| **Ошибка CRC** — ответ искажён | Помехи, нет общего провода или терминатора, неверная чётность, два мастера на линии |
| **Исключение** — прибор отказал | Адрес, функция или значение не подходят |

Разбор каждого случая — в разделе [Решение проблем](../troubleshooting.md).
