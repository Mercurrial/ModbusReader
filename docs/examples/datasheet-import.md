# Карта из паспорта прибора

В паспорте почти любого прибора с Modbus есть таблица регистров. Её не нужно
перепечатывать в программу руками — достаточно получить таблицу в Excel или
CSV и [импортировать](../guide/map-editor.md#import).

## 1. Получите таблицу

- Если производитель даёт карту в Excel или CSV — берите её.
- Если только PDF — выделите таблицу в PDF-просмотрщике и вставьте в Excel,
  или откройте PDF в Word / LibreOffice и скопируйте таблицу оттуда.
- Уберите из таблицы объединённые ячейки, заголовки разделов посреди
  таблицы и сноски — каждая строка должна быть одним регистром.

Пример того, что должно получиться (сохраните как `meter.csv`):

```text
Адрес;Наименование;Тип;Доступ;Ед. изм.;Множитель
40001;Напряжение фазы A;UINT16;R;В;0.1
40002;Ток фазы A;UINT16;R;А;0.01
40003;Активная мощность;INT32;R;Вт;1
40005;Частота;UINT16;R;Гц;0.01
40010;Адрес прибора;UINT16;RW;;1
40011;Скорость связи;UINT16;RW;;1
30001;Температура платы;INT16;R;°C;0.1
```

Колонки могут называться как угодно и идти в любом порядке — их
сопоставление задаётся при импорте. Обязательна только колонка адреса.

## 2. Импортируйте

1. **Изменить карту** (++ctrl+2++) → **«Импорт из таблицы…»** → выберите
   файл.
2. Проверьте, что колонки распознались: «Адрес» → *Адрес*,
   «Наименование» → *Имя*, «Тип» → *Тип*, «Множитель» → *Масштаб*. Лишние
   колонки — *не использовать*.
3. **Формат адреса** — главное решение:

    | В паспорте | Выбирайте |
    |---|---|
    | `40001`, `40002`, `30001` | **4x / 3x (40001 = регистр 0)** |
    | `1`, `2`, `3` и написано «номер регистра» | **С единицы (1 = регистр 0)** |
    | `0`, `0x0000`, `0000h` | **Как в файле (с нуля)** |

    В примере выше — 4x: `40001` станет holding-регистром 0, а `30001` —
    input-регистром 0. Если вы забудете выбрать 4x, программа предупредит:
    слишком много адресов больше 30000.
4. Посмотрите на итог внизу: сколько регистров будет импортировано и нет
   ли замечаний — непонятных адресов, повторов.
5. **Заменить текущую карту** → **Импортировать**.

Типы из паспортов программа понимает сама: `INT16` → `SHORT`, `UINT16` /
`WORD` → `UINT16`, `INT32` / `DINT` → `LONG`, `UINT32` / `DWORD` → `UINT32`,
`REAL` / `FLOAT32` → `FLOAT` и так далее. Если тип не распознан — будет
`SHORT`, поправьте в редакторе.

## 3. Доведите в редакторе

- Проверьте **размер** 32-битных регистров: `INT32` на 40003 займёт 40003 и
  40004, следующий регистр — 40005. Внизу редактора видно **пересечения
  адресов** — их быть не должно.
- Добавьте **перечисления** для регистров режимов: «Инженерные единицы…» →
  `0 = Стоп`, `1 = Работа`.
- Добавьте английские имена, если с картой будут работать в английском
  интерфейсе.

## 4. Проверьте на приборе

1. Подключитесь (++f5++) и найдите регистр, значение которого вы знаете:
   адрес прибора, скорость связи, напряжение сети ≈ 230 В.
2. Если там чужое значение — адреса сдвинуты на единицу. Посмотрите
   соседние строки: если правильное значение у соседа, переимпортируйте с
   другим форматом адреса.
3. Если 32-битные значения огромные или отрицательные — не тот
   [порядок байт](../modbus/data-types.md#byte-order).
4. Если прибор отвечает исключением 02 на весь блок — возможно, это
   input-регистры, а не holding (или наоборот): поменяйте **Область**.

Сохраните карту (++ctrl+s++) или весь проект — и карта готова для этой
модели прибора навсегда. Поделиться картой с другими можно через
[Issues](https://github.com/Mercurrial/ModbusReader/issues) — есть шаблон
«Карта регистров прибора».
