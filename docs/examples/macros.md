# Примеры макросов

Макросы ниже написаны для **демо-проекта** (термоконтроллер) — имена
регистров взяты из него. Для своего прибора замените имена на свои. Справка
по командам — в разделе [Макросы](../guide/macros.md).

!!! note "Сырые значения"
    `read()` возвращает значение без масштаба из карты. В демо-проекте у
    «Мощности нагревателя» множитель 0.1, поэтому ниже она умножается на 0.1
    вручную.

## Замеры в таблицу

Каждые 5 секунд — строка со всеми регистрами карты. Через час — таблица на
720 строк, которую можно сохранить в Excel.

```python
for i in range(720):
    row = {"#": i, "время": timestamp()}
    row.update(read_all())          # все регистры карты: {имя: значение}
    record(row)
    wait(5)
```

Для долгих записей без макроса есть [логгер](../guide/logger.md): он пишет
CSV прямо на диск.

## Перебор уставок с ожиданием стабилизации

Задать уставку, дождаться, пока температура войдёт в допуск, записать время
выхода на режим. Если за 10 минут не вышла — отметить и перейти к
следующей.

```python
SETPOINTS = [20, 25, 30, 35]
TOLERANCE = 0.5          # °C
LIMIT = 600              # с на одну уставку

for sp in SETPOINTS:
    write("Уставка температуры", sp)
    t0 = now()
    reached = False
    while now() - t0 < LIMIT:
        t = read("Температура")
        if abs(t - sp) <= TOLERANCE:
            reached = True
            break
        wait(2)
    record({"уставка": sp,
            "температура": round(t, 2),
            "вышла на режим": "да" if reached else "нет",
            "время, с": round(now() - t0)})
    log("уставка", sp, "готово" if reached else "не вышла за", LIMIT, "с")
```

## Сверка с эталоном

Проверить, что настройки прибора совпадают с эталонными, — например, после
замены прибора или обновления прошивки.

```python
EXPECTED = {
    "Уставка температуры": 25.0,
    "Режим": 1,
    "Задержка аварии": 30,
}

bad = 0
for name, want in EXPECTED.items():
    got = read(name)
    ok = abs(got - want) < 0.01
    bad += 0 if ok else 1
    record({"регистр": name, "эталон": want, "прибор": got,
            "итог": "OK" if ok else "РАСХОЖДЕНИЕ"})
log("расхождений:", bad)
```

## Ожидание события с таймаутом

Включить нагреватель и засечь, через сколько сработает дискретный вход
(в демо — «Дверь открыта»). Пример показывает, как ждать условия, не
зависая навсегда.

```python
def wait_for(name, value, timeout, step=0.1):
    """Ждать, пока регистр станет равен value. Вернуть время или None."""
    t0 = now()
    while now() - t0 < timeout:
        if read(name) == value:
            return now() - t0
        wait(step)
    return None

write("Нагреватель", 1)
dt = wait_for("Дверь открыта", 1, timeout=30)
write("Нагреватель", 0)
if dt is None:
    log("событие не наступило за 30 с")
else:
    record({"событие": "Дверь открыта", "через, с": round(dt, 2)})
```

## Статистика значения

Сто отсчётов — минимум, максимум, среднее и размах. Полезно, чтобы оценить
шум датчика.

```python
values = []
for i in range(100):
    values.append(read("Ток датчика"))
    wait(0.2)

avg = sum(values) / len(values)
record({"отсчётов": len(values), "мин": min(values), "макс": max(values),
        "среднее": round(avg, 3), "размах": max(values) - min(values)})
```

## Мощность в инженерных единицах

Масштаб из карты в макросе не применяется — его легко применить самому.

```python
for i in range(60):
    raw = read("Мощность нагревателя")       # 573
    record({"время": timestamp(), "мощность, %": round(raw * 0.1, 1)})
    wait(1)
```

## Поиск регистров без документации

Прочитать подряд адреса 0…99 как `UINT16` и записать в таблицу все, что
ответили. Адресов нет в карте, поэтому тип указан явно. Нет ответа или
исключение — адрес пропускается.

```python
for addr in range(100):
    try:
        v = read(addr, "UINT16")
    except RuntimeError:
        continue
    record({"адрес": hex(addr), "значение": v, "hex": hex(v)})
log("готово")
```

Input-регистры — так же, с приставкой: `read("IR " + str(addr), "UINT16")`.
Для быстрого обзора есть ещё [сканер](../guide/scanner.md) в режиме
«Регистры».

## Повторить при сбое связи

Обёртка, которая повторяет чтение несколько раз, прежде чем сдаться, —
для длинных проверок на шумной линии.

```python
def read_retry(name, tries=3):
    for k in range(tries):
        try:
            return read(name)
        except RuntimeError:
            log("нет ответа", name, "попытка", k + 1)
            wait(0.5)
    return None

for i in range(10):
    record({"#": i, "температура": read_retry("Температура")})
    wait(1)
```

## Рецепт: последовательность записей

Записать несколько регистров по шагам с паузами — например, пусковая
последовательность.

```python
STEPS = [
    ("Режим", 0, 1),                  # стоп, подождать 1 с
    ("Уставка температуры", 25, 0.5),
    ("Вентилятор", 1, 0.5),
    ("Режим", 1, 0),                  # работа
]
for name, value, pause in STEPS:
    write(name, value)
    log("записано", name, "=", value)
    wait(pause)
```
