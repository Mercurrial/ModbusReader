# Проверка SCADA эмулятором

Задача: проверить мастер — SCADA, панель оператора, контроллер или свою
программу, — когда прибора нет. ModbusReader в режиме
[эмулятора](../guide/slave.md) отвечает мастеру как прибор по карте
регистров.

## Что понадобится

- **Карта регистров прибора** — из его паспорта ([импорт из
  Excel](datasheet-import.md)) или демо-проект для пробы.
- **Связь между мастером и эмулятором:**
    - мастер на **другом компьютере** или это контроллер — два USB-RS-485
      адаптера, соединённые A–A, B–B, GND–GND;
    - мастер на **этом же компьютере** — пара виртуальных COM-портов: всё,
      что пишется в один, выходит из другого.

## Виртуальные COM-порты

=== "Windows — com0com"

    1. Установите [com0com](https://com0com.sourceforge.net/) — бесплатный
       драйвер пары виртуальных портов.
    2. В его утилите **Setup** создайте пару и дайте портам привычные имена,
       например `COM10` ↔ `COM11` (флажок «use Ports class», чтобы порты
       было видно в программах).
    3. Проверьте, что `COM10` и `COM11` появились в **Диспетчере устройств**.

=== "Linux — socat"

    ```bash
    socat -d -d pty,raw,echo=0,link=/tmp/ttyV0 pty,raw,echo=0,link=/tmp/ttyV1
    ```

    Пока команда работает, `/tmp/ttyV0` и `/tmp/ttyV1` — пара связанных
    портов. Имя порта в ModbusReader можно ввести вручную.

## Шаги

1. **Эмулятор.** Откройте в ModbusReader карту прибора, перейдите на
   **Эмулятор (Slave)** (++ctrl+9++), выберите порт `COM11`, адрес прибора
   `1` и нажмите **«Запустить»**. Скорость и чётность — из **Настройки →
   Подключение**, например 115200 8N1.
2. **Значения.** Двойным щелчком задайте в таблице эмулятора правдоподобные
   значения: температуру, режим, состояние. Помните, что здесь сырые
   значения — без масштаба из карты.
3. **Мастер.** В SCADA (или другом мастере) настройте порт `COM10`, ту же
   скорость, чётность и адрес прибора `1`. Запустите опрос.
4. **Смотрите обмен.** В журнале эмулятора видно каждый запрос мастера, а
   колонки **Чтений / Записей / Последнее** показывают, какие регистры он
   трогает. Если SCADA читает адрес, которого нет в карте, — в журнале будет
   исключение 02, и это повод проверить [адресацию](../modbus/addressing.md)
   в проекте SCADA (частая ошибка — смещение на единицу).
5. **Записи.** Поменяйте уставку из SCADA — значение в таблице эмулятора
   изменится. Поменяйте значение в эмуляторе — SCADA должна его увидеть.

### Мастер — вторая копия ModbusReader

Чтобы просто «оживить» демо-проект без прибора, мастером может быть сам
ModbusReader: запустите вторую копию программы, откройте тот же проект,
выберите порт `COM10` и нажмите **«Подключить»**. Две копии используют
один файл настроек; удобнее, если вторая — [портативная
версия](../install.md#windows) из отдельной папки: у неё свои настройки.

## Что ещё проверить

- **Таймауты мастера:** поставьте в эмуляторе **задержку** ответа 500–1500 мс
  и посмотрите, как мастер переживает медленный прибор.
- **Пропажу прибора:** остановите эмулятор — мастер должен показать потерю
  связи, а после запуска восстановить её.
- **Порядок байт:** задайте FLOAT 24.6 и проверьте, что SCADA показывает
  24.6, а не −775.2 — иначе в SCADA другой [порядок
  байт](../modbus/data-types.md#byte-order).
- **Широковещательные команды:** запись на адрес 0 эмулятор примет без
  ответа, как настоящий прибор.
