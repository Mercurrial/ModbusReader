# Автоматика на дашборде

Задача: **включать вентилятор, когда температура выше 30 °C, и выключать,
когда ниже 28 °C** — без единой строчки кода. Пример собран на
демо-проекте; провода и виджеты описаны в разделе [Дашборд](../guide/dashboard.md).

```text
                 +-----------------+     +------------------------+
            +--->| Условие: t > 30 |---->| Кнопка: Вентилятор = 1 |
+--------+  |    +-----------------+     +------------------------+
| Таймер |--+
| 1000 мс|  |    +-----------------+     +------------------------+
+--------+  +--->| Условие: t < 28 |---->| Кнопка: Вентилятор = 0 |
                 +-----------------+     +------------------------+
```

Раз в секунду таймер посылает импульс в оба условия. Верхнее пропускает
его, только если жарко, — и кнопка включает вентилятор. Нижнее — только если
остыло, — и вторая кнопка выключает. Между 28 и 30 °C не происходит ничего:
это гистерезис, вентилятор не будет «дребезжать» у порога.

## Шаги

1. Откройте **Дашборд** (++ctrl+6++) и нажмите **«Редактировать»**
   (++ctrl+e++).
2. **Добавить виджет → Таймер.** Период — `1000` мс. **Автостарт** можно не
   включать: таймер запускается щелчком.
3. **Добавить виджет → Условие.** Регистр — «Температура», условие `>`,
   сравнить с `30`.
4. Ещё одно **Условие**: «Температура», `<`, `28`.
5. **Добавить виджет → Кнопка.** Регистр — «Вентилятор» (coil),
   записать значение `1`. Заголовок — «Вентилятор: вкл».
6. Ещё одна **Кнопка**: «Вентилятор», значение `0`, заголовок
   «Вентилятор: выкл».
7. **Провода:** протяните от правой точки таймера к левой точке каждого
   условия, и от правой точки каждого условия — к своей кнопке.
8. Нажмите **«Готово»**, подключитесь (++f5++) и щёлкните по таймеру — он
   пойдёт. Импульсы видно: провода подсвечиваются, виджеты вспыхивают;
   закрытое условие тоже вспыхивает, но дальше импульс не пускает.

Сохраните проект (++ctrl+s++) — дашборд с проводами сохранится в нём.

## Важные свойства

- **В режиме редактирования ничего не пишется в прибор** — таймеры
  останавливаются, кнопки неактивны.
- **Условие без данных закрыто.** Если связь пропала и температура
  неизвестна, условие импульс не пропустит — цепочка не будет писать
  вслепую.
- Таймер пишет **каждый** период, пока условие выполнено: в примере
  вентилятор раз в секунду получает команду «включить». Для большинства
  приборов это нормально; если прибор не любит частые записи — увеличьте
  период.

## Вариации

- **Ручной пуск последовательности:** Кнопка «Старт» → Кнопка «Режим = 1» →
  Кнопка «Вентилятор = 1». Одно нажатие — несколько записей по цепочке.
- **Уставка с ползунка в два регистра:** Ползунок → Кнопка, привязанная к
  другому регистру. Значение ползунка уйдёт по проводу, и кнопка запишет
  его в свой регистр.
- **Аварийное отключение:** Таймер → Условие «Дверь открыта = 1» → Кнопка
  «Нагреватель = 0».

Когда логика становится сложнее «если — то», переходите на
[макросы](macros.md): там циклы, переменные и таблица результатов.

!!! warning "Не для систем безопасности"
    Автоматика дашборда работает, пока открыта программа и есть связь. Это
    инструмент наладки и испытаний, а не замена ПЛК и защитных блокировок.
