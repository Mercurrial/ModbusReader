A free Modbus RTU tool for Windows

ModbusReader commissions and monitors Modbus RTU devices over RS-485: a register map with names and units, live trends, an HMI-style dashboard, a bus scanner, a sniffer, Python macros and a Modbus slave simulator.

Download for Windows Source on GitHub

Windows 10 / 11 · free · open source (GPL-3.0) · English and Russian UI · auto-update

Features

Modbus RTU master

Holding and input registers, coils and discrete inputs (FC 01–06, 15, 16). 24 data types — UINT16, INT32, FLOAT, DOUBLE, BCD, strings, bit words — with per-type byte order, scaling and enumerations.

Modbus slave simulator

The app answers a master as a device would, from the open register map — test a SCADA, HMI or PLC without the real hardware.

RS-485 sniffer

Listen to a live line through a second adapter without sending a byte: who asked whom, what came back, where the CRC broke.

Bus scanner

Find devices on the line by address, or live registers on one device.

Console with frame decoding

A traffic log that decodes every frame, and raw frame sending with automatic CRC16.

Logger and macros

Hours-long CSV logging that opens in Excel; Python scripts that read and write registers by name and build result tables.

Trends and dashboard

Live trends

Any register on a chart in one click, with min / max / average and windows from 10 s to 10 min.

Dashboard with 14 widget kinds

Gauges, lamps, buttons, switches, sliders and timers; wires between them give simple automation with no code.

Install

  • ModbusReader-Setup.exe — installer (all users or just you);
  • portable ModbusReader.exe — on the Releases page;
  • you need a USB-to-RS-485 (or RS-232) adapter with its vendor driver; no Python required.

The first launch opens a demo project, so you can try the app without a device. If Windows SmartScreen warns you, click “More info” → “Run anyway”: the app is not signed with a paid certificate yet.

FAQ

Is there a free alternative to Modbus Poll and Modbus Slave?

Yes — ModbusReader is both a master and a slave simulator, free and open source under GPL-3.0.

How do I test a SCADA or PLC without a real device?

Turn on the slave simulator: the app answers the master from the open register map. On one PC, a pair of virtual COM ports (for example com0com) is enough.

Does it run on Linux or macOS?

Ready-made builds are for Windows. On Linux and macOS it runs from source (Python 3.10+); see the README.
