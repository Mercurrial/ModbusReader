# Дашборд

Дашборд (++ctrl+6++) — свой пульт оператора: виджеты расставляются свободно
и привязываются к регистрам карты. Значения обновляются, пока идёт опрос.
А **провода** между виджетами дают простую автоматику: «таймер → кнопка →
запись в прибор».

![Дашборд демо-проекта: стрелочный прибор, график, лампы, биты, ползунок, тумблер](../images/dashboard.png)

## Два режима

- **Работа** — виджеты живые: кнопки пишут, таймеры идут, ползунки
  двигаются. Случайно сдвинуть ничего нельзя.
- **Редактирование** (кнопка **«Редактировать»**, ++ctrl+e++) — виджеты
  перетаскиваются и меняют размер, появляются порты для проводов.
  **В этом режиме в прибор ничего не пишется**: таймеры остановлены,
  кнопки неактивны. **«Готово»** — вернуться в работу.

## Виджеты

**Добавить виджет** → выберите вид и регистр из карты.

### Показания

| Виджет | Для чего |
|---|---|
| **Значение** | Крупное число с единицами и мини-графиком последних значений |
| **Лампа** | Загорается, когда значение выше порога: флаги «вкл», «авария». Есть инверсия |
| **Полоса** | Шкала от «мин» до «макс» — сразу видно, где значение в диапазоне |
| **Прибор** | Стрелочный прибор со шкалой и зоной аварии |
| **Биты** | Регистр разобран на 16 бит — для слов состояния; только чтение |
| **График** | Тренд последних значений прямо на дашборде |

### Управление

| Виджет | Что пишет |
|---|---|
| **Кнопка** | При нажатии записывает заданное значение в регистр |
| **Ввод** | Введите значение, ++enter++ — оно уйдёт в регистр |
| **Тумблер** | Переключает регистр между двумя значениями |
| **Ползунок** | Тянете — выбираете, отпускаете — запись. Для уставок; есть шаг и режим «Писать при перетаскивании» |
| **Выбор** | Список подписей из перечисления регистра; выбор сразу пишется |

### Логика

| Виджет | Что делает |
|---|---|
| **Таймер** | Периодически «нажимает» всё, к чему подключён проводом. Период в мс, автостарт. Щелчок в работе — пуск/стоп |
| **Условие** | Пропускает импульс дальше, только если значение своего регистра удовлетворяет условию: `>`, `≥`, `<`, `≤`, `=`, `≠` |
| **Надпись** | Просто текст — подписать зону пульта |

Двойной щелчок по виджету в режиме редактирования — **«Настройка виджета»**:
заголовок, единицы, мин/макс, пороги аварии **«ниже»** и **«выше»**, значения
для кнопки и тумблера, шаг ползунка, условие и т. д.

## Провода и автоматика

В режиме редактирования у виджетов, которые могут участвовать в цепочке,
появляются точки-порты: **выход справа, вход слева**. Протяните мышью от
правой точки одного виджета к левой точке другого — получится провод.

Как работает цепочка:

- Когда виджет срабатывает — нажата кнопка, тикнул таймер, введено
  значение, — он выполняет своё действие, а **импульс идёт по проводам
  дальше**, и каждый подключённый виджет выполняет своё.
- **Кнопка, тумблер, ввод, ползунок, выбор** на входящий импульс пишут
  своё значение в регистр. Если источник — ввод, ползунок или выбор, по
  проводу уходит **его значение**, и следующий виджет запишет именно его.
- **Таймер** на входящий импульс запускается или останавливается.
- **Условие** пропускает импульс, только если условие выполнено. Если
  значение регистра неизвестно (нет связи) — **не пропускает**: цепочка не
  будет писать в прибор вслепую.

Импульсы видно: провод подсвечивается, виджеты вспыхивают — понятно, куда
дошла цепочка и где остановилась.

Пример: **Таймер (1000 мс) → Условие (Температура > 30) → Кнопка
«Вентилятор: 1»** — раз в секунду проверять температуру и включать
вентилятор, если жарко. Пошагово — в примере
[Автоматика на дашборде](../examples/dashboard-automation.md).

Удалить провод — выделите его и нажмите ++del++, или правый щелчок →
**«Удалить связь»**.

## Редактирование

| Действие | Как |
|---|---|
| Выделить несколько | Рамкой по пустому месту, ++ctrl++ + щелчок — добавить |
| Копировать / вырезать / вставить | ++ctrl+c++ / ++ctrl+x++ / ++ctrl+v++ |
| Дублировать | ++ctrl+d++ |
| Выделить всё | ++ctrl+a++ |
| Сдвинуть | Стрелки, с ++shift++ — на 10 |
| Удалить виджет или провод | ++del++ |
| Масштаб | Колесо мыши, ++ctrl+0++ — сброс |
| Панорама | Перетаскивание правой кнопкой |

При перетаскивании виджеты прилипают к краям и центрам соседей; с
зажатым ++alt++ — ставятся точно по пикселям.

## Несколько дашбордов

В одном проекте может быть сколько угодно дашбордов — например, «Пульт» и
«Наладка». Меню **«Управление дашбордами»**: новый, переименовать,
дублировать, удалить, **сохранить в файл** `.mbdash` и **загрузить из файла**
— чтобы перенести пульт в другой проект. Все дашборды сохраняются в
проекте `.mbproj`.

Правый щелчок по виджету → **«Добавить в наблюдение»** выносит его регистр в
[окно наблюдения](trends.md#watch).
