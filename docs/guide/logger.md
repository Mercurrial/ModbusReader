# Логгер

**Логгер** (++ctrl+8++) записывает значения всех регистров карты в CSV —
на часы и сутки. Файл сразу открывается в Excel двойным щелчком.

![Логгер: файл, период, новый файл по размеру и последние строки](../images/logger.png)

1. **Файл** — куда писать (кнопка **«Выбрать файл…»**). Если файл уже есть,
   программа спросит: перезаписать или взять новое имя.
2. **Записывать каждые** — период, от 100 мс (по умолчанию 1000 мс).
3. **Новый файл после** — размер части, от 1 до 2000 МБ (по умолчанию 50).
   Следующие части получают имена `имя_002.csv`, `имя_003.csv`…
4. **Запятая как разделитель (Excel RU)** — включите для русского Excel:
   разделитель колонок `;`, дробная часть через запятую. Выключите — будет
   `,` и точка.
5. **«Начать запись»**.

Под настройками — колонки будущего файла, прогноз объёма («13 колонок ·
примерно 3600 строк и 0.4 МБ в час») и последние записанные строки.

## Формат файла

Одна строка — один момент времени, одна колонка — один регистр:

```text
timestamp;0x0000 Температура, °C;0x0005 Мощность нагревателя, %;IR 0x0000 Напряжение питания, В
2026-10-16 12:00:00.000;24,6;57,3;24,12
2026-10-16 12:00:01.000;24,7;57,1;24,13
```

- Значения — в инженерных единицах, как в таблице; у перечислений —
  подпись.
- Если регистр в этом цикле не прочитался, ячейка пустая — колонки не
  сдвигаются.
- Кодировка UTF-8 с BOM — кириллица в Excel читается правильно.
- Набор колонок фиксируется при старте: чтобы добавить регистр, остановите
  запись и начните заново.

Логгер пишет то, что приходит при опросе, — опрос должен идти. Для долгой
записи включите **Настройки → Подключение → Молча опрашивать при потере
связи**, чтобы короткий обрыв линии не остановил всё до утра. Если диск
заполнился или файл заблокирован, запись останавливается с сообщением, а
программа продолжает работать.
