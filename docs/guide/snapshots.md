# Снимки

**Снимки** (++ctrl+7++) отвечают на вопрос «что изменилось?». Запомните все
значения, поменяйте что-то на приборе — с его панели, из SCADA, другой
программой — и сравните.

![Снимки: было, стало, разница и состояние каждого регистра](../images/snapshots.png)

1. Подключитесь и дождитесь, пока значения придут.
2. **«Снять снимок»** — программа запомнит текущие значения всех регистров
   карты.
3. Измените что-нибудь на приборе.
4. **«Сравнить с текущим»** — таблица покажет по каждому регистру **Было**,
   **Стало**, **Разницу** и **Состояние**: изменилось, без изменений,
   добавлен или удалён (если карта поменялась между снимками).

Фильтры **Все / Изменённые / Добавленные / Удалённые** оставляют нужное;
сверху — итог: «Изменилось: 4 · добавлено: 0 · удалено: 0 · без изменений:
9». Значения сравниваются в инженерных единицах — так, как их показывает
таблица.

**«Сохранить…»** записывает снимок в файл `.mbsnap`, **«Открыть…»**
загружает его обратно — можно сравнить прибор с тем, каким он был вчера или
на другом объекте. Типичные применения: найти, в каком регистре лежит
параметр, который меняется с панели прибора; проверить, что после
обновления прошивки настройки не сбросились.
