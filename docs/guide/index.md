# Руководство

Окно ModbusReader устроено так:

- **Слева** — панель экранов. Сверху **«Мониторинг»**: карта регистров и
  дашборд. Ниже **«Инструменты»**. Зелёная точка у пункта — инструмент
  работает в фоне (например, идёт запись логгера). Панель сворачивается до
  значков.
- **Сверху** — проект и текущий экран, параметры связи и кнопка
  **«Подключить»** (++f5++).
- **Внизу** — журнал обмена, строка отправки сырых кадров и строка
  состояния: адрес прибора, счётчики, статистика линии.

Клавиша ++f1++ (кнопка **«Справка»**) на любом экране запускает короткий тур
именно по этому экрану.
