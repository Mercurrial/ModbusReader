# Настройки и горячие клавиши

**Настройки** — ++ctrl+comma++ или кнопка внизу панели слева. Изменения
применяются кнопкой **«Сохранить»**; если уйти без сохранения, программа
предупредит.

## Подключение

Порт, скорость, чётность, стоп-биты; период опроса, таймаут ответа, число
неудачных опросов до потери связи, пауза между запросами; порядок байт для
SHORT, LONG и FLOAT; поведение при потере связи. Всё это подробно — в
разделах [Подключение к прибору](../connect.md) и
[Типы данных и порядок байт](../modbus/data-types.md).

## Общие

- **Язык интерфейса** — русский или английский, меняется без перезапуска.
  Переключатель RU/EN есть и в шапке окна.
- **Запуск** — открывать карту или проект, с которыми работали в прошлый раз.
- **Обновления** — проверять автоматически (при запуске и раз в несколько
  часов) и кнопка **«Проверить сейчас»**. Ставится обновление только после
  вашего согласия — см. [Установка](../install.md#updates).

## Внешний вид

![Четыре варианта оформления одного окна](../images/themes.png)

- **Тема** — тёмная или светлая (быстрое переключение — ++ctrl+t++).
- **Цветовая схема** — тёмные: Графит, Карбон, Полночь, Сланец; светлые:
  Бумага, Снег, Песок.
- **Контраст** — мягкий, обычный, высокий. Высокий — для яркого цеха или
  проектора.
- **Акцентный цвет** — 12 вариантов для выделения и индикаторов.
- **Шрифт интерфейса** — любой установленный в системе, **размер шрифта** и
  **высота строки** таблицы; образец обновляется сразу.

## Таблица

Видимость колонок (адрес, имя, тип, доступ, значение, новое значение),
**зебра**, **моноширинный шрифт значений** и **подсветка изменений** —
строка вспыхивает, когда значение меняется.

## Графики

Окно по умолчанию (10 с … 10 мин), автомасштаб оси Y для новых графиков,
сглаживание линий, длина истории на регистр, ширина панели графиков. См.
[Графики](trends.md).

## Журнал

Показывать ли журнал обмена, его высота, автопрокрутка к новым записям,
**уровень детализации** (Мин, Норм, Debug) и **лимит записей** (50…2000,
старые удаляются).

## Горячие клавиши

Полный список — в **Настройки → Горячие клавиши**.

### Глобально

| Действие | Клавиши |
|---|---|
| Подключить / отключить | ++f5++ |
| Окно наблюдения | ++f6++ |
| Справка — тур по текущему экрану | ++f1++ |
| Настройки | ++ctrl+comma++ |
| Тёмная / светлая тема | ++ctrl+t++ |
| Поиск регистра | ++ctrl+f++ |
| Закрыть настройки или редактор | ++esc++ |

### Окна

| Окно | Клавиши |
|---|---|
| Карта регистров | ++ctrl+1++ |
| Редактор карты | ++ctrl+2++ |
| Консоль | ++ctrl+3++ |
| Сканер | ++ctrl+4++ |
| Сниффер | ++ctrl+5++ |
| Дашборд | ++ctrl+6++ |
| Снимки | ++ctrl+7++ |
| Логгер | ++ctrl+8++ |
| Эмулятор (Slave) | ++ctrl+9++ |
| Макросы | ++ctrl+m++ |

### Проект и карта

| Действие | Клавиши |
|---|---|
| Новый проект | ++ctrl+n++ |
| Открыть проект | ++ctrl+o++ |
| Сохранить проект | ++ctrl+s++ |
| Новая карта | ++ctrl+shift+n++ |
| Открыть карту | ++ctrl+shift+o++ |

### Таблица регистров

| Действие | Клавиши |
|---|---|
| Ввести новое значение | ++f2++ |
| Следующая / предыдущая строка колонки | ++tab++ / ++shift+tab++ |
| Меню регистра | правая кнопка мыши |
| Просмотр области памяти | двойной щелчок |
| Обмен регистра в журнал | щелчок по точке состояния |

### Редактор карты

| Действие | Клавиши |
|---|---|
| Отменить / повторить | ++ctrl+z++ / ++ctrl+shift+z++ |
| Сохранить карту / как… | ++ctrl+s++ / ++ctrl+shift+s++ |
| Удалить строку | ++del++ |

### Дашборд

| Действие | Клавиши |
|---|---|
| Режим редактирования | ++ctrl+e++ |
| Масштаб / сброс | колесо, ++ctrl+plus++ / ++ctrl+minus++ / ++ctrl+0++ |
| Копировать / вырезать / вставить | ++ctrl+c++ / ++ctrl+x++ / ++ctrl+v++ |
| Дублировать виджет | ++ctrl+d++ |
| Выделить всё | ++ctrl+a++ |
| Удалить виджет или провод | ++del++ |
| Сдвиг выделения | стрелки, с ++shift++ — на 10 |
