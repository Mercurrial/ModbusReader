# Сканер

**Сканер** (++ctrl+4++) отвечает на два вопроса: *кто есть на линии* и
*какие адреса отвечают у прибора*. Он работает через открытое подключение —
сначала нажмите **«Подключить»** (++f5++). Опрос карты на время скана
продолжается.

![Сканер: найденные приборы с временем ответа](../images/scanner.png)

## Режимы

**Устройства** — перебор адресов прибора (Slave ID) в диапазоне 1…247. Каждому
отправляется чтение одного holding-регистра с адресом 0. Найденным
считается прибор, который ответил:

- **Отвечает** — вернул данные;
- **Жив (исключение)** — ответил ошибкой Modbus. Это тоже **находка**: прибор
  на линии и разобрал запрос, просто у него нет регистра 0. Читайте
  его по адресам из документации.

**Регистры** — перебор адресов holding-регистров у **одного** прибора (его
адрес задаётся рядом). Для каждого ответившего адреса показано сырое
значение — так можно найти живые регистры прибора без документации.

По каждой находке — время ответа в миллисекундах. В конце — итог: «Найдено
5 из 32 · 6.4 с». Скан идёт в фоне; повторное нажатие кнопки его
останавливает.

## Скорость скана

Молчащий адрес стоит целый **таймаут ответа** (**Настройки → Подключение →
Таймаут ответа**, по умолчанию 1000 мс). Перебор всех 247 адресов при
таймауте 1 с займёт около четырёх минут. Чтобы ускорить:

- сузьте диапазон, если примерно знаете адрес;
- уменьшите таймаут до 200–300 мс — большинство приборов отвечает за
  10–50 мс. Не забудьте вернуть его для обычной работы.

## Если неизвестна скорость { #unknown-baud }

Сканер ищет на одной скорости и чётности — тех, что заданы в настройках.
Если параметры прибора неизвестны, перебирайте их по очереди: начните с
**9600 8N1**, **19200 8N1**, **9600 8E1**, **19200 8E1**, затем 38400 и
115200 — для каждого варианта переподключитесь (++f5++ дважды) и запустите
скан устройств с узким диапазоном (например, 1…10). Заводской адрес
большинства приборов — 1.

Ошибки CRC в статистике линии при переборе — признак, что скорость близка,
но не та, или не та чётность.
