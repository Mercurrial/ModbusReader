# Макросы

**Макросы** (++ctrl+m++) — скрипты на обычном Python, которые читают и пишут
регистры прибора, ждут, проверяют условия и собирают **таблицу
результатов**. Так автоматизируются приёмочные проверки, калибровка,
перебор уставок, долгие замеры.

![Макросы: редактор скрипта, таблица результатов и журнал](../images/macros.png)

## Как это работает

1. Подключитесь к прибору (++f5++) — без связи макрос не запустится.
2. Напишите скрипт в редакторе и нажмите **«Запустить»**.
3. Каждый вызов `record(...)` добавляет строку в **Результаты**; `log(...)`
   пишет в **Журнал** внизу.
4. **«Стоп»** прерывает макрос в любой момент — даже бесконечный цикл.
5. Готовую таблицу — в **CSV** или **XLSX** (Excel).

Макрос выполняется в фоне: можно переключиться на другие экраны, а его
запросы пойдут вперемешку с опросом карты. Последний скрипт сохраняется
между запусками; **«Сохранить»** / **«Открыть»** работают с файлами `.py`.
Кнопка **«Справка»** открывает список команд прямо в программе.

## Первый макрос

```python
# Прочитать температуру 10 раз с интервалом в секунду
for i in range(10):
    t = read("Температура")
    record({"#": i, "время": timestamp(), "температура": t})
    wait(1)
log("готово")
```

## Команды

### Регистры

`read(регистр)`
:   Прочитать регистр и вернуть значение: число, 0/1 для битов, текст для
    `STRING`.

`write(регистр, значение)`
:   Записать значение. Возвращает записанное значение. Если прибор не
    подтвердил запись — ошибка.

`reg(регистр)`
:   Объект регистра с методами `.read()`, `.write(v)` и свойством `.value`
    (читает при каждом обращении) — удобно, если регистр нужен много раз:
    `t = reg("Температура")`, затем `t.value`.

`read_all()`
:   Прочитать все числовые регистры карты и вернуть словарь
    `{имя: значение}`. Удобно для строки отчёта: `record(read_all())`.

**Как назвать регистр:**

| Способ | Пример |
|---|---|
| По имени из карты (русскому или английскому, регистр букв не важен) | `read("Температура")`, `read("temperature")` |
| По адресу holding-регистра | `read(0x0A)`, `read(10)`, `read("0x0A")` |
| По адресу в другой таблице | `read("IR 0x01")`, `read("CO 5")`, `read("DI 3")` |
| Адрес, которого нет в карте, — с типом | `read(0x0100, "FLOAT")`, `write(0x0200, 5, "UINT16")` |

Если регистра нет в карте и тип не указан, макрос остановится с понятной
ошибкой.

!!! warning "Сырые значения"
    Макросы работают с **сырыми** значениями — без масштаба и перечислений из
    карты. У регистра «Мощность нагревателя» с множителем 0.1 `read()` вернёт
    573, а не 57.3; режим «Работа» вернётся как 1. Масштаб применяйте сами:
    `read("Мощность нагревателя") * 0.1`.

### Время и ожидание

`wait(секунды)` · `sleep(секунды)`
:   Пауза; можно дробную: `wait(0.5)`. «Стоп» прерывает её сразу.

`now()`
:   Текущее время в секундах (дробное) — для замера длительности:
    `t0 = now()` … `log(now() - t0)`.

`timestamp()`
:   Дата и время строкой `ГГГГ-ММ-ДД ЧЧ:ММ:СС` — удобная колонка таблицы.

### Результаты и журнал

`record(словарь)` · `record(колонка=значение, …)`
:   Добавить строку в таблицу результатов. Колонки создаются из ключей
    автоматически, в порядке первого появления: `record({"шаг": 1, "t": 24.6})`
    или `record(шаг=1, t=24.6)`.

`log(...)` · `print(...)`
:   Вывести сообщение в журнал: `log("уставка", sp, "готова")`.

## Что доступно из Python

Обычный Python: переменные, циклы `for` и `while`, условия, функции,
списки и словари, `try` / `except`. Из встроенных функций —
`abs`, `min`, `max`, `round`, `sum`, `len`, `range`, `enumerate`, `zip`,
`map`, `filter`, `sorted`, `reversed`, `int`, `float`, `str`, `bool`, `list`,
`dict`, `tuple`, `set`, `divmod`, `pow`, `bin`, `hex`, `oct`, `ord`, `chr`,
`format`, `repr`, `any`, `all`, `isinstance`.

**Нельзя:** `import` (модулей `math`, `time` и других нет), `open`, `eval`,
`exec` и имена с двойным подчёркиванием (`__class__` и т. п.). Это защитные
ограждения от случайностей, а не песочница: макрос — это код, который
выполняется с правами программы. Поэтому скрипт, **открытый из файла**,
программа перед первым запуском попросит подтвердить. Запускайте только то,
чему доверяете.

## Ошибки

- **Синтаксическая ошибка** — макрос не запустится, в журнале будет номер
  строки.
- **Нет ответа от прибора** — `read()` и `write()` выбрасывают ошибку
  (`RuntimeError`); на одну операцию отводится до 5 секунд. Её можно
  поймать, чтобы пережить случайный таймаут:

    ```python
    try:
        v = read("Температура")
    except RuntimeError:
        v = None
        log("нет ответа, пропускаю")
    ```

- Любая необработанная ошибка останавливает макрос; в журнале — тип ошибки
  и номер строки. Строки, уже попавшие в таблицу, остаются.

При закрытии программы с работающим макросом или с невыгруженными
результатами программа предупредит.
