# Эмулятор (Slave)

**Эмулятор** (++ctrl+9++) превращает ModbusReader в прибор: программа
отвечает чужому мастеру — SCADA, панели оператора, контроллеру — по
открытой карте регистров. Так можно отладить верхний уровень, когда
прибора ещё нет, он далеко или его жалко.

![Эмулятор: обслуживаемые регистры, их значения, счётчики чтений и записей, журнал запросов](../images/slave.png)

## Запуск

1. Откройте карту регистров (или проект) — эмулятор отвечает по её
   адресам и типам.
2. На экране **Эмулятор (Slave)** выберите **порт** и **адрес прибора**
   (1–247). Скорость, чётность и стоп-биты берутся из **Настройки →
   Подключение** — они должны совпадать с мастером.
3. Нажмите **«Запустить»**. Строка состояния покажет: «Отвечаю как прибор с
   адресом 1 на COM4, 115200 8N1. Обслуживается 13 рег.».

У порта может быть только один владелец: если на этом же порту идёт опрос,
эмулятор не запустится (и наоборот). Для проверки мастера **этой же
программы** нужны два порта: два адаптера с нуль-модемом или пара
виртуальных COM-портов (например, [com0com](https://com0com.sourceforge.net/))
и вторая копия ModbusReader. Пошагово — в примере
[Проверка SCADA эмулятором](../examples/test-scada.md).

## Значения

Таблица показывает все обслуживаемые регистры: адрес, имя, тип и
**значение**, которое прочитает мастер. **Двойной щелчок** по значению —
задать новое. Значения здесь **сырые**, как их хранит прибор, без масштаба
из карты: чтобы мастер увидел 57.3 % у регистра с множителем 0.1, введите
573. FLOAT, строки и остальные типы вводятся как обычно — программа сама
разложит их по регистрам в настроенном порядке байт. Начальные значения
берутся из колонки **«По умолч.»** карты, остальные — ноль.

Когда мастер пишет в регистр, значение в таблице меняется. Колонки
**Чтений**, **Записей** и **Последнее** показывают, какие регистры мастер
трогает и когда — удобно проверить, что SCADA опрашивает всё, что должна.

**«Взять из карты»** — обновить список регистров после правки карты; уже
введённые значения сохраняются. Если карта изменилась во время работы,
изменения применятся при следующем запуске.

## Как эмулятор отвечает

| Запрос мастера | Ответ |
|---|---|
| FC 03 / 04 — чтение регистров | Данные из таблицы |
| FC 01 / 02 — чтение coils / discrete inputs | Биты из таблицы |
| FC 06 / 16 — запись регистров | Эхо и новое значение в таблице |
| FC 05 / 15 — запись coils | Эхо и новое значение |
| Адрес вне карты (или диапазон заходит за её край) | Исключение 02 |
| Неверное количество или значение | Исключение 03 |
| Другие функции | Исключение 01 |
| Чужой адрес, неверный CRC, короткий кадр | Молчание |
| Широковещательная запись (адрес 0) | Запись без ответа |

Эмулятор не проверяет доступ R/RW из карты: запись в регистр, который в
карте помечен «только чтение», он тоже примет. Если в карте нет
input-регистров, чтение FC 04 обслуживается из holding-регистров — так
работают многие простые приборы.

**Задержка** — пауза перед каждым ответом в миллисекундах: эмуляция
медленного прибора, чтобы проверить таймауты мастера.

## Журнал

Внизу — каждый запрос мастера: «FC03 чтение 0x0000 × 11», «FC06 запись
0x000A × 1», исключения и кадры без ответа с причиной (неверный CRC,
другой адрес, широковещательный запрос). Под таблицей — итог: запросов,
ответов, исключений, без ответа.
