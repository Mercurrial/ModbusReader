# Редактор карты и импорт

Карта регистров описывает прибор: какие регистры у него есть, где они
лежат, какого они типа и как их показывать. Редактор открывается кнопкой
**«Изменить карту»** над таблицей, ++ctrl+2++ или из меню проекта
(**«Создать карту регистров…»**).

![Редактор карты регистров: адрес, область, имена, тип, размер, доступ, единицы](../images/editor.png)

## Колонки

| Колонка | Смысл |
|---|---|
| Адрес | Адрес с нуля. Считается сам от предыдущего регистра с учётом его размера; двойной щелчок — задать вручную (`0x10`, `10h` или `16`). Регистры, идущие вплотную за ним, сдвинутся вместе с ним |
| Область | 4x Holding, 3x Input, 0x Coil, 1x Discrete — см. [Области и адреса](../modbus/addressing.md) |
| Имя (RU) / Имя (EN) | Имя на русском и английском; в таблице показывается имя языка интерфейса |
| Тип | Тип данных — подсказка у каждого типа в списке; см. [Типы данных](../modbus/data-types.md) |
| Размер | Сколько адресов занимает регистр. Для фиксированных типов — сам, для `STRING` задаётся: 10 = 20 символов |
| Доступ | R, RW или W. Input и discrete — всегда R |
| Ед. | Единица измерения: `°C`, `В`, `%` |
| По умолч. | Значение, с которого начинает [эмулятор](slave.md) |
| Комментарий | Любой текст для себя |

Для coils и discrete inputs тип всегда `BOOL`, размер 1 — программа
выставляет это сама при выборе области.

## Действия

- **Добавить регистр** — новая строка после последней.
- **Перетаскивание** строки мышью меняет порядок (++esc++ во время
  перетаскивания — отмена).
- Правый щелчок по строке: **Инженерные единицы…**, **Дублировать**,
  **Удалить** (++del++).
- ++ctrl+z++ / ++ctrl+shift+z++ — отменить и повторить.
- **Очистить всё** — удалить все регистры.
- **JSON** — показать карту как текст файла.

Внизу редактора — счётчики: сколько регистров, есть ли **пересечения
адресов** (FLOAT на 0x0002 и регистр на 0x0003 занимают одно место) и
**дубликаты имён**. Пересечения почти всегда означают ошибку в карте.

### Масштаб и перечисление

**Инженерные единицы…** в меню строки:

- **Множитель** и **Смещение**: `отображаемое = сырое × множитель + смещение`.
  Прибор передаёт 573, множитель 0.1 — в таблице 57.3.
- **Перечисление** — по строке на значение:

    ```text
    0 = Стоп
    1 = Работа
    2 = Авария
    ```

Подробнее — в разделе [Типы данных](../modbus/data-types.md#scaling).

## Применить и сохранить

- **Применить** — показать карту в главном окне, **не** сохраняя файл.
  Удобно проверить и поправить на ходу.
- **Сохранить** (++ctrl+s++) / **Сохранить как…** (++ctrl+shift+s++) — в
  отдельный файл карты `.json`. Имя файла предлагается из поля имени карты.
- Если карта — часть [проекта](projects.md), достаточно сохранить проект:
  карта хранится внутри него.

Закрыть редактор — ++esc++; при несохранённых правках программа спросит,
что с ними делать.

## Импорт из CSV и Excel { #import }

У большинства приборов карта регистров есть в паспорте — таблицей. Её не
нужно перепечатывать: в редакторе нажмите **«Импорт из таблицы…»** и выберите
файл `.csv`, `.txt`, `.xlsx` или `.xlsm`.

Программа сама определит кодировку (UTF-8, Windows-1251), разделитель
(`;`, `,`, табуляция) и попробует угадать колонки по заголовкам — «Адрес»,
«Наименование», «Тип», «Ед. изм.», «Address», «Name», «Data type»… Догадку
всегда можно поправить.

В окне импорта:

1. **Лист** — для Excel-книги с несколькими листами.
2. **Первая строка — заголовок** — снимите, если заголовка нет.
3. **Формат адреса** — самое важное:
    - **Как в файле (с нуля)** — `0`, `0x0010`, `10h` — адрес протокола;
    - **С единицы (1 = регистр 0)** — в паспорте «регистр 1» — это адрес 0;
    - **4x / 3x (40001 = регистр 0)** — нотация Modicon; таблица берётся из
      первой цифры: 4xxxx — holding, 3xxxx — input, 1xxxx — discrete.

    Если в файле много адресов больше 30000, программа предупредит: похоже на
    формат 4x — иначе вся карта сместится.
4. **Колонки** — для каждой колонки файла выберите, что в ней: Адрес, Имя,
   Тип, Доступ, Длина, Ед. изм., Масштаб, Смещение, Комментарий, Имя (EN),
   Область — или «не использовать». Обязателен только адрес.
5. Внизу — сколько регистров будет импортировано и список замечаний:
   неразобранные адреса, адреса вне 0…0xFFFF, повторы.
6. **Заменить текущую карту** или **Добавить к текущей** → **Импортировать**.

Программа понимает типы так, как их пишут производители: `int16`, `uint16`,
`word`, `int32`, `dword`, `real`, `float32`, `lreal`, `bcd`, `string`,
`ascii`… Доступ — `R`, `RO`, `R/W`, `чтение`, `запись`… Область — `holding`,
`HR`, `4x`, `FC03`, `input`, `coil`, `дискретный вход`…

Пошаговый пример — [Карта из паспорта прибора](../examples/datasheet-import.md).

## Формат файла карты { #file-format }

Карта — обычный JSON, его удобно хранить в git и править руками:

```json
{
  "format": "modbusreader.profile",
  "version": 2,
  "name": "Термоконтроллер",
  "registers": [
    {"addr": 0, "name": "Температура", "name_en": "Temperature",
     "type": "FLOAT", "length": 2, "rw": "R", "unit": "°C"},
    {"addr": 4, "name": "Режим", "type": "UINT16", "length": 1, "rw": "RW",
     "enum": {"0": "Стоп", "1": "Работа", "2": "Авария"}},
    {"addr": 5, "name": "Мощность", "type": "UINT16", "length": 1, "rw": "R",
     "unit": "%", "scale": 0.1},
    {"addr": 0, "area": "coil", "name": "Нагреватель", "type": "BOOL",
     "length": 1, "rw": "RW"}
  ]
}
```

- `addr` — адрес с нуля (можно строкой `"0x10"`);
- `area` — `input`, `coil` или `discrete`; без него — holding;
- `rw` — `R`, `RW` или `W`;
- `scale`, `offset`, `enum`, `unit`, `default`, `comment`, `name_en` —
  необязательные.

Файлы, сохранённые старыми версиями программы, открываются всегда: формат
версионирован и обновляется при загрузке.
