# Карта регистров

Главный экран программы (++ctrl+1++): все регистры прибора в одной таблице.
Пока идёт опрос, значения обновляются на каждом цикле.

![Карта регистров: адрес, имя, тип, доступ, значение и новое значение](../images/main.png)

## Колонки

| Колонка | Что показывает |
|---|---|
| ● | [Точка состояния](#state): свежее ли значение, и кнопка журнала этого регистра |
| Адрес | Адрес с нуля в hex с приставкой таблицы: `0x000A`, `IR 0x0001`, `CO 0x0000`, `DI 0x0000` — см. [Области и адреса](../modbus/addressing.md) |
| Имя | Имя из карты; в английском интерфейсе — английское имя, если оно задано |
| Тип данных | `FLOAT`, `UINT16`, `BOOL`… — см. [Типы данных](../modbus/data-types.md) |
| Доступ | `R` — только чтение, `RW` — чтение и запись, `W` — только запись |
| Значение | Текущее значение с масштабом, единицами и подписью перечисления |
| Новое значение | Поле для записи в прибор — только у регистров, которые можно записать |

Лишние колонки можно скрыть: **Настройки → Таблица**. Там же — высота
строки, зебра, моноширинный шрифт значений и вспышка строки при изменении
значения.

## Точка состояния { #state }

Точка слева от адреса показывает, насколько свежее значение:

| Точка | Что значит |
|---|---|
| Зелёная | Значение свежее |
| Жёлтая | Связь есть, но прибор перестал отвечать по этому регистру |
| Серая | Нет связи — показано последнее полученное значение |
| Пустой кружок | Значения ещё не было |

Наведите на точку — подсказка скажет, сколько секунд назад пришло значение.
«Перестал отвечать» программа отмеряет по самому регистру: тот, что
опрашивается раз в 5 секунд, станет жёлтым не раньше чем через 15.

Рядом с точкой — кнопка **журнала обмена** (значок консоли). Она появляется
при наведении на строку; щелчок пишет в журнал запросы и ответы именно
этого регистра, кнопка остаётся залитой, пока журнал включён. То же — в меню
правого щелчка: **«Показывать обмен в журнале»**.

## Запись значения

1. Щёлкните по полю с карандашом в колонке **«Новое значение»** (или
   выделите строку и нажмите ++f2++). Поле есть только у регистров с
   доступом `RW` или `W`; у регистров только для чтения ячейка пустая.
2. Введите значение и нажмите ++enter++. ++tab++ / ++shift+tab++ переходят к
   следующей / предыдущей строке колонки.

Значение вводится в **инженерных единицах** — если у регистра задан
масштаб, программа сама пересчитает его в сырое. Для битов (coils)
подходят `1`/`0`, `on`/`off`, `вкл`/`выкл`, `да`/`нет`. Для регистра с
перечислением — число.

Результат — в журнале: **«Запись успешна»** или **«Запись не подтверждена»**
с адресом слова, которое прибор не принял. Без подключения запись не
отправляется и не копится: в журнале появится сообщение, что она не ушла.

Правый щелчок по строке → **«Записать значение…»** открывает то же самое в
отдельном окне.

## Меню регистра

Правый щелчок по строке:

- **Добавить на график** / **Убрать с графика** — живой
  [график](trends.md) справа (до 8 одновременно).
- **Добавить в наблюдение** — в [окно наблюдения](trends.md#watch)
  (++f6++).
- **Показывать обмен в журнале** — запросы и ответы этого регистра в
  журнале (как кнопка у [точки состояния](#state)).
- **Показывать как** — десятичное, шестнадцатеричное или двоичное. Для
  регистров с масштабом, перечислением и строк не предлагается: у
  инженерного значения нет «hex-вида».
- **Копировать значение**, **Копировать адрес**.
- **Записать значение…** — для регистров с записью.

## Поиск

++ctrl+f++ — поле **«Поиск регистра…»** над таблицей. Фильтрует по имени и
адресу; рядом счётчик «13 из 13» показывает, сколько строк видно.

## Журнал обмена

Внизу окна — каждый кадр обмена в шестнадцатеричном виде с разбором:

```text
[12:00:01.316] [TX] → [01 03 00 00 00 02 C4 0B]  FC03 · чтение 2 рег. с 0x0000
[12:00:01.330] [RX] ← [01 03 04 41 C4 CC CD 3B 67]  данные: [41C4 CCCD]
```

- Вкладки **Все / Передача / Приём / Ошибки** фильтруют журнал, поле
  **«Найти в журнале»** ищет по тексту.
- Журнал можно сохранить в `.txt` или очистить.
- **Кнопка журнала** у [точки состояния](#state) включает подробный журнал
  именно для этого регистра — удобно, когда нужно увидеть сырые слова одного
  FLOAT и подобрать порядок байт.
- Уровень детализации, высота панели и лимит записей — **Настройки →
  Журнал**.

Под журналом — строка отправки сырых кадров. Подробно о ней — в разделе
[Консоль](console.md).

## Статистика линии

В правом нижнем углу — счётчики **TX / RX / ERR** и среднее время ответа.
Щелчок открывает подробности:

| Счётчик | Что значит |
|---|---|
| Запросов отправлено / Ответов получено | Доля ответов — главный показатель качества связи |
| Без ответа (таймаут) | Проводка, адрес, скорость |
| Ошибки CRC | Ответ искажён: помехи, нет терминатора, неверная чётность |
| Исключения Modbus | Прибор отказал: адрес или функция не поддерживаются |
| Время ответа | Последнее, среднее, минимум и максимум |

Счётчики обнуляются при каждом подключении и кнопкой **«Сбросить»**. Как
действовать по ним — в разделе [Решение проблем](../troubleshooting.md).

## Области памяти

Регистр типа `MEMORY_AREA` — это не одно значение, а большой массив
(например, буфер осциллограммы или журнал событий прибора). Он не
опрашивается циклически; **двойной щелчок** открывает просмотр массива:
число каналов, раскладка (**чередование** Ch1, Ch2, Ch3… или **блоками**),
тип и порядок байт. Кнопка **«Запросить данные»** читает массив частями по
125 регистров.

## Изменить карту

Кнопка **«Изменить карту»** над таблицей (или ++ctrl+2++) открывает
[редактор карты](map-editor.md).
