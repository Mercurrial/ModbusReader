# Проекты и файлы

## Проект `.mbproj`

**Проект** — один файл на объект или прибор. В нём:

- **параметры связи** — порт, скорость, чётность, стоп-биты, адрес прибора,
  период опроса, таймаут, паузы и порядок байт;
- **карта регистров**;
- **все дашборды** с виджетами и проводами;
- раскладка окна — какой экран был открыт, высота журнала, ширина панели
  графиков.

Открыли проект — программа готова к работе с этим прибором: остаётся нажать
**«Подключить»**.

| Действие | Клавиши |
|---|---|
| Новый проект | ++ctrl+n++ |
| Открыть проект | ++ctrl+o++ |
| Сохранить проект | ++ctrl+s++ |

Меню проекта — по щелчку на его названии в шапке окна: там же **«Сохранить
проект как…»**, **«Недавние проекты»**, открыть или создать отдельную
карту. **Новый проект** закрывает текущую карту и дашборды, но оставляет
параметры связи.

Проекты открываются и сохраняются в папке **Projects** рядом с программой
(у портативной версии — рядом с exe); там же лежит демо-проект. При запуске
программа открывает проект или карту, с которыми вы работали в прошлый раз
(**Настройки → Общие → Запуск**). Установщик связывает `.mbproj`
с программой — проект открывается двойным щелчком.

## Карта `.json`

**Карта регистров** — отдельный файл только со списком регистров, без
параметров связи и дашбордов. Ею удобно обмениваться: одна карта на модель
прибора, а проектов с ней — сколько угодно объектов. Формат — в разделе
[Редактор карты](map-editor.md#file-format).

| Действие | Клавиши |
|---|---|
| Новая карта | ++ctrl+shift+n++ |
| Открыть карту | ++ctrl+shift+o++ |

Если открыть файл карты как проект, программа поймёт это и откроет его как
карту.

## Какие ещё файлы бывают

| Файл | Откуда | Что внутри |
|---|---|---|
| `.mbdash` | [Дашборд](dashboard.md) → «Сохранить дашборд в файл…» | Один дашборд — чтобы перенести его в другой проект |
| `.mbsnap` | [Снимки](snapshots.md) → «Сохранить…» | Значения всех регистров на момент снимка |
| `.csv` | [Логгер](logger.md) | Запись значений: строка — момент времени, колонка — регистр |
| `.csv`, `.xlsx` | [Макросы](macros.md) → CSV / XLSX | Таблица результатов макроса |
| `.py` | [Макросы](macros.md) → «Сохранить» | Текст макроса |
| `.txt` | Журнал обмена → «Сохранить журнал…» | Журнал обмена |

Все форматы ModbusReader — текстовые (JSON или CSV): их можно читать,
сравнивать и хранить в системе контроля версий.
