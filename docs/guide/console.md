# Консоль

**Консоль** (++ctrl+3++) — журнал обмена во весь экран и строка отправки
произвольных кадров. Та же строка есть и под журналом на экране карты
регистров (кнопка справа от журнала её показывает и прячет).

![Консоль: журнал обмена с разбором кадров и строка отправки](../images/console.png)

## Отправка кадра

Две строки:

- **Команда** — кадр без CRC в hex: адрес прибора, функция, данные.
  Пробелы, запятые и `0x` можно ставить как угодно: `01 03 00 00 00 02`,
  `0x01, 0x03, 0x00, 0x00, 0x00, 0x02` и `010300000002` — одно и то же.
  Каждый байт — две цифры: `00`, а не `0`. Справа программа сразу показывает
  посчитанный **CRC**.
- **Пакет** — то, что реально уйдёт в порт: команда + CRC. Его можно
  поправить руками — например, испортить CRC, чтобы проверить реакцию
  прибора, или отправить кадр чужого протокола. Ручная правка помечается
  значком **«изменён»**, пока вы снова не измените команду.

++enter++ или **«Отправить»** — отправить. ++arrow-up++ / ++arrow-down++ —
история последних 20 команд (сохраняется между запусками).

Ответ прибора появляется в журнале строкой `[RX]`. Консоль работает через
открытое подключение: сначала нажмите **«Подключить»** (++f5++). Кадр из
консоли уходит вне очереди, между запросами опроса.

**По Modbus TCP** команда пишется так же — адрес (Unit ID), функция, данные, —
а вместо CRC программа добавляет заголовок **MBAP**: номер транзакции, ноль
протокола и длину. Строка «Пакет» показывает кадр так, как он уйдёт в сеть;
номер транзакции растёт с каждым кадром. При [RTU по
TCP](../modbus/rtu-over-tcp.md) кадр уходит как в COM-порт — с CRC.

## Полезные кадры

Прибор 1, CRC консоль добавит сама:

| Задача | Команда |
|---|---|
| Прочитать 2 holding-регистра с адреса 0 | `01 03 00 00 00 02` |
| Прочитать 1 input-регистр с адреса 0 | `01 04 00 00 00 01` |
| Прочитать 8 coils с адреса 0 | `01 01 00 00 00 08` |
| Записать 25 в holding-регистр 2 | `01 06 00 02 00 19` |
| Включить coil 0 | `01 05 00 00 FF 00` |
| Выключить coil 0 | `01 05 00 00 00 00` |
| Записать FLOAT 25.0 (ABCD) в регистры 2–3 одной командой | `01 10 00 02 00 02 04 41 C8 00 00` |
| То же для прибора 10 | `0A 10 00 02 00 02 04 41 C8 00 00` |

Структура кадров — в разделе [Что такое Modbus RTU](../modbus/index.md), коды
функций — в [Функции и ошибки](../modbus/functions.md).

## Журнал обмена

В журнале — каждый кадр с меткой времени, направлением (`TX` — передано,
`RX` — принято), байтами и разбором: функция, адрес, количество, данные,
эхо записи. Фильтры **Все / Передача / Приём / Ошибки**, поиск, сохранение в
`.txt` и очистка — над журналом. Подробность разбора — **Настройки →
Журнал → Уровень детализации**.
