# Графики и наблюдение

## Графики

Любой регистр можно вывести на живой график: правый щелчок по строке карты
→ **«Добавить на график»**. Карточки графиков появляются в панели
**«Мониторинг в реальном времени»** справа; одновременно — до 8.

![Живой график значения регистра: текущее значение, минимум, максимум, среднее](../images/trend.png){ width="420" }

На карточке:

- крупно — **текущее значение** с единицами и изменение за окно (стрелка);
- **мин / макс / ср.** за видимое окно;
- окно времени: **10 с · 30 с · 2 мин · 10 мин**;
- ⏸ **Пауза** — остановить прокрутку и рассмотреть участок;
- ⤢ **Развернуть** (или двойной щелчок по графику) — на весь экран;
- ⌖ **Автомасштаб Y** — подогнать ось под видимые данные;
- 🗑 **Очистить** — стереть накопленную историю;
- ✕ — убрать график.

Карточки можно переставлять перетаскиванием. Если связь пропала, линия
гаснет, а на карточке видно, сколько времени нет данных.

**Настройки → Графики:** окно по умолчанию, автомасштаб для новых графиков,
сглаживание линий (на слабом компьютере с множеством графиков его можно
выключить), длина истории на регистр и ширина панели.

Панель графиков и журнал обмена скрываются и показываются кнопкой **«Вид»**
справа в шапке окна (пункты **«Панель графиков»** и **«Журнал обмена»**).

## Окно наблюдения { #watch }

**Наблюдение** (++f6++) — маленькое плавающее окно с выбранными регистрами.
Оно видно с любого экрана программы и может висеть **поверх всех окон**
(кнопка-булавка) — например, рядом со SCADA или документацией прибора.

![Окно наблюдения: значения, минимум, максимум и время изменения](../images/watch.png){ width="380" }

- Добавить: правый щелчок по строке карты или по виджету дашборда →
  **«Добавить в наблюдение»**.
- По каждому регистру видно значение, мин / макс с момента добавления и
  когда значение менялось в последний раз.
- **Двойной щелчок по «Записать»** — ввести новое значение и записать
  его в прибор (++enter++).
- Правый щелчок по строке: **Выше / Ниже**, **Сбросить мин/макс**,
  **Убрать из наблюдения**.

Значения в окне обновляются, пока идёт опрос.
