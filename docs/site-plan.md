# План развития сайта modbusreader.ru

Цель — самая полная вики по Modbus на русском и английском, со
ссылками на ModbusReader там, где программа реально помогает. Целевой запрос
— «Modbus»; путь к нему лежит через сотни узких запросов (коды функций и
ошибок, приборы, RS-485, CRC), затем средние («modbus rtu», «modbus tcp»),
и только потом общий.

Файл не публикуется (mkdocs.yml → `exclude_docs`). Отмечайте сделанное.

## Правила

- **Каждая страница сразу на двух языках**: `page.md` (RU) и `page.en.md`
  (EN) в одном коммите, с одинаковыми `{ #id }` у заголовков. Английский —
  не дословный перевод, а текст под англоязычные запросы (свой
  `seo_title` и `description`).
- Адреса существующих страниц не меняем (на них уже есть позиции).
  Если переносить — только с редиректом.
- Справочные страницы нейтральны, как статья энциклопедии. Программа — в
  одном блоке «В ModbusReader» в конце раздела, по делу.
- Каждая страница: `seo_title` под запрос, `description` 140–200 знаков,
  H1, ссылки на 3–5 соседних статей, ссылка вверх на обзор раздела.
- Факты — по спецификациям Modbus.org (Application Protocol v1.1b3,
  Serial Line v1.02, TCP/IP Implementation Guide v1.0b) и документации
  производителей. Карты регистров приборов — только из руководств
  производителя, со ссылкой на источник.
- Диаграммы — только ASCII (шрифт кода без псевдографики).
