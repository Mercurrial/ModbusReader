# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии.
Установленные копии получают их через автообновление.

| Версия | Поддерживается |
|---|:---:|
| последний выпуск | ✓ |
| более ранние | — |

## Как сообщить об уязвимости

Не создавайте открытую задачу (Issue) — до выхода исправления описание
уязвимости не должно быть публичным.

Сообщите о ней закрыто через GitHub:
**[Security → Report a vulnerability](https://github.com/Mercurrial/ModbusReader/security/advisories/new)**.

Опишите:

- что именно уязвимо и к чему это может привести;
- шаги воспроизведения или пример (файл проекта, скрипт, кадр Modbus);
- версию программы и способ установки.

Получение сообщения будет подтверждено в течение 7 дней. После проверки
согласуем срок исправления; автор сообщения будет указан в описании выпуска,
если не попросит иного.

## Что входит в область

- **Механизм обновлений.** Программа загружает обновления только по HTTPS с
  GitHub и устанавливает файл, лишь если его SHA-256 совпадает с контрольной
  суммой, которую GitHub публикует для файла выпуска. Любой обход этой
  проверки — уязвимость.
- **Подпись выпусков.** Файлы для Windows подписываются сертификатом
  SignPath Foundation только после сборки в GitHub Actions и ручного
  утверждения ([политика подписи кода](https://modbusreader.ru/code-signing/)).
  Способ получить такую подпись в обход этой сборки — уязвимость.
- **Открытие файлов.** Карты регистров (`.json`), проекты (`.mbproj`),
  дашборды (`.mbdash`), снимки (`.mbsnap`) и импортируемые таблицы могут
  прийти от третьих лиц. Выполнение кода или запись за пределами выбранного
  пользователем файла при их открытии — уязвимость.
- **Макросы.** Макрос — это код на Python. Программа ограничивает его
  возможности (без `import` и служебных атрибутов) и запрашивает
  подтверждение перед запуском скрипта из файла, но это защитное ограждение, а
  не изолированная среда: запускайте только скрипты, которым доверяете.
  Способы обойти эти ограничения из скрипта, открытого в программе, также
  принимаются как сообщения о безопасности.

## Что не входит в область

- Протокол Modbus RTU не предусматривает аутентификации и шифрования; любой,
  кто подключён к линии RS-485, может читать и записывать регистры. Это
  свойство протокола, а не программы.
- Предупреждение Windows SmartScreen при первом запуске: неподписанные
  выпуски (до подключения подписи) и только что вышедшая версия, у которой
  ещё мало скачиваний.
